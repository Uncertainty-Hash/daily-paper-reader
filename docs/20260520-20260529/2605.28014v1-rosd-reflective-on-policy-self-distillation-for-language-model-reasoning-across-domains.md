## 摘要
在线策略自蒸馏通过为在线策略 rollout 提供密集的 token 级监督来提升大型语言模型的推理性能。然而，现有的在线策略自蒸馏方法在领域内推理上的增益有限，并且对领域外问题的泛化能力较差。我们识别出两个关键原因：让自教师以已验证解为条件会鼓励模仿训练领域的参考轨迹而非针对错误的修正；对整个响应应用蒸馏会覆盖有效的推理前缀并强化过拟合。我们提出反思式在线策略自蒸馏（ROSD），这是一个通过反思引导、错误定位的蒸馏将参考解模仿转化为针对性推理修正的框架。对于每个 rollout，ROSD 使用自反思器提取修正思路并定位第一个错误片段。修正思路引导自教师产生针对性的监督，而定位的错误片段则将蒸馏限制在需要修正的区域。这种设计修正了有缺陷的推理同时保留了有效前缀。在多个领域内和领域外推理基准上的实验表明，与标准在线策略自蒸馏相比，ROSD 整体上取得了更强的领域内推理性能，并显著提升了领域外泛化能力。代码已开源在 https://github.com/ZiqiZhao1/ROSD。

## Abstract
On-policy self-distillation (OPSD) improves the reasoning performance of large language models (LLMs) by providing dense token-level supervision for on-policy rollouts. However, existing OPSD methods often yield limited gains on in-domain reasoning and generalize poorly to out-of-domain problems. We identify two key causes: conditioning the self-teacher on a verified solution encourages imitation of training-domain reference trajectories rather than error-specific correction, and applying distillation to the full response can overwrite valid reasoning prefixes and reinforce overfitting.   We propose Reflective On-policy Self-Distillation (ROSD), a framework that turns reference-solution imitation into targeted reasoning correction through reflection-guided, error-localized distillation. For each rollout, ROSD uses a self-reflector to extract a corrective idea and locate the first erroneous span. The corrective idea guides the self-teacher toward targeted supervision, while the localized error span restricts distillation to where correction is needed. This design corrects flawed reasoning while preserving valid prefixes. Experiments on multiple in-domain and out-of-domain reasoning benchmarks show that ROSD yields stronger in-domain reasoning performance overall and substantially better out-of-domain generalization than standard OPSD. Code is available at https://github.com/ZiqiZhao1/ROSD.

## 一、核心问题与整体含义（研究动机与背景）

- 大型语言模型（LLM）的推理能力可以通过后训练进一步提升，其中**在线策略自蒸馏（OPSD）** 通过对当前模型采样的 rollout 提供密集的 token 级监督，克服了传统 RLVR（如 GRPO）仅依赖结果奖励的稀疏信号缺陷。
- 但现有 OPSD 方法（如 SDPO）存在两大问题：
  1. **自教师以已验证解为条件**，导致模型模仿参考轨迹而非纠正自身错误，学习到领域特定的表达风格。
  2. **全响应蒸馏**会覆盖已经正确的推理前缀，且强化过拟合，损害领域外泛化能力。
- 实证显示：标准 OPSD 的域内性能后期下滑，域外性能急剧恶化（图1左）。
- 为此，论文提出 **ROSD（Reflective On-policy Self-Distillation）**，将模仿参考解转化为**针对性的错误修正**，通过**反思引导 + 错误局部化蒸馏**，保留有效推理前缀，仅修正错误区域。

## 二、方法论：核心思想与关键技术

- **核心思想**：将标准 OPSD 的“自教师条件于完整正确解”替换为“自教师条件于自反射器提取的修正想法”，并将蒸馏损失**限制在第一个错误 token 之后的后缀**。

### 关键技术步骤（文字描述）

1. **错误聚焦的自反射（Error-Focused Self-Reflection）**
   - 对每个问题 \(x\)，采样 \(G\) 个 rollout，分为正确集 \(Y^+\) 和错误集 \(Y^-\)。
   - 对于 **错误 rollout** \(y^-\)：配对一个最短正确 rollout \(y^*\)，使用自反射器（与模型权重共享）生成：
     - **修正想法 \(e\)**：说明错误原因及如何修正。
     - **错误引文 \(q\)**：从 \(y^-\) 中提取的第一个错误位置的精确子串。
   - 对于 **正确 rollout** \(y^+\)：仅生成一个解释为何正确的 \(e\)，不产生错误引文。
   - 提示模板见图2。

2. **引文定位的自蒸馏（Quote-Localized Self-Distillation）**
   - 对每个错误 rollout \(y^-\)，通过 `Locate(q, y^-)` 找到错误引文在 \(y^-\) 中的起始 token 位置 \(k\)。
   - 定义掩码 \(m_t = 0\)（当 \(t < k\)），\(m_t = 1\)（当 \(t \ge k\)）；若无法匹配则回退为全响应蒸馏（\(k=0\)）。
   - 自教师条件于当前 rollout 前缀 \(y_{<t}\) **以及**修正想法 \(e\)，输出下一 token 分布。
   - 训练损失（公式9）：
     \[
     L_{\text{ROSD}}(\theta) = \sum_{t=1}^T m_t \cdot \text{KL}\big(\pi_\theta(\cdot|x,y_{<t}) \;\|\; \text{stopgrad}[\pi_\theta(\cdot|x,e,y_{<t})]\big)
     \]
     实践中使用 Jensen-Shannon 散度（JSD）。
   - 学生、自教师、自反射器共享同一基础模型（无额外大模型开销）。

## 七、优点

1. **方法创新**：将 OPSD 从“模仿参考解”转向“针对性修正错误”，反思引导自教师、错误局部化蒸馏，逻辑合理且有效。
2. **简单高效**：无需额外模型或外部教师，反射器与自教师共享模型权重；训练开销与 SDPO 相近，且后期 rollout 更短、更稳定。
3. **泛化提升显著**：在域外场景大幅优于标准 OPSD，缓解了密集蒸馏导致的过拟合问题。
4. **实验全面**：涵盖多领域、多骨干、消融、动态分析、效率对比，结论有说服力。
5. **开源代码**：提供了可复现的代码仓库。

## 八、不足与局限

1. **域外泛化未超越 GRPO**：尽管在自蒸馏框架下改善显著，但域外平均分仍低于 GRPO，表明还需在保持密集监督同时进一步减少训练风格依赖。
2. **反射器质量依赖**：错误引文匹配率约 50%，匹配失败时回退为全响应蒸馏，可能降低效果；模型规模越小（Qwen-4B）匹配率越低。
3. **实验覆盖率有限**：仅在 Qwen 系列 4B/8B 上验证，未在更大模型（如 32B、70B）或其他架构（如 Llama、DeepSeek）上测试，通用性待进一步评估。
4. **应用限制**：需同时采样多个 rollout 并运行反射器，对小批量推理场景可能增加额外延迟；且反射要求模型具备较好的指令跟随能力。

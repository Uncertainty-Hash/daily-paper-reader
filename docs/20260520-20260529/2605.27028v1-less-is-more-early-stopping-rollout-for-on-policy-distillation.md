## 摘要
在线策略蒸馏最近作为一种有前景的替代标准序列级模仿的方法出现，它通过教师模型对学生自己的 rollout 进行评分来训练学生。然而，我们观察到这种范式存在“离策略教师衰减”问题：对于后面的 token，由于学生的早期轨迹作为上下文对教师来说是离策略的，教师产生纠正性分数的能力会衰减，并可能退回到预训练阶段学到的 token 补全行为。我们通过实验验证了这个问题，并提出早期停止 rollout (ESR) 来解决它：一种简单而有效的蒸馏策略，仅将 rollout 生成限制在前几个响应 token 上。我们表明 ESR 在模型大小、系列、任务和训练制度上均超越了完整的 rollout OPD 性能，并展现出更高的 GPU 效率和训练稳定性，特别是在跨模型系列场景下。我们进一步研究了这一惊人性能背后的机制，发现 ESR 的“级联对齐”和“子模式承诺”效应，这可能解释为什么它有效甚至有时超过教师模型性能。此外，我们表明这种基于位置的 token 选择策略不能完全由 KL 散度和熵信号解释。

## Abstract
On-policy distillation has recently emerged as a promising alternative to standard sequence-level imitation, training a student by scoring its own rollouts with a teacher model. However, we observe ``Off-policy Teacher Decay'' problem in this paradigm: for the later tokens, with student's earlier trajectory as context that is off-policy to the teacher, the teacher's ability to produce a corrective score would decay, and may fall back to token-completion behavior learned in the pre-training stage. We empirically verify this problem, and we propose Early Stopping Rollout (ESR) to fix it: a simple yet effective distillation strategy that simply restricts the rollout generation to the first   response tokens. We show that ESR both surpasses the full rollout OPD performance across model size, family, tasks and training regime, and exhibit much higher GPU efficiency and training stability, especially under cross model family scenarios. We further investigate the mechanism behind this surprising performance and discovered "Cascading Alignment" and "Sub-mode Commitment" effect of ESR that may explain why it works effectively and even sometimes exceeding the teacher model performance. Besides, we show that this position-based token selection strategy cannot be fully explainable by KL divergence and entropy signals.

## 1. 核心问题与整体含义（研究动机和背景）

- **研究背景**：在线策略蒸馏（On-Policy Distillation, OPD）是一种有前景的大语言模型（LLM）蒸馏范式。它让学生模型（student）生成自己的响应序列（rollout），再由教师模型（teacher）对序列中每一个 token 进行评分，作为软标签来优化学生。
- **核心问题**：作者观察到 OPD 存在“离策略教师衰减”（Off-policy Teacher Decay）问题。具体来说，在生成序列的后半部分，教师模型的评分条件不仅包含原始提示，还包含学生模型自己生成的历史 token。由于学生的历史轨迹对教师而言是“离策略”的（即不符合教师自身的分布），教师会逐渐偏离其应有的纠正性评分行为，退回到预训练阶段学到的自动补全行为，导致评分信号失效。实验表明，教师对学生生成的前缀进行续写时，准确率会快速下降至学生基线水平。
- **研究意义**：准确、可靠的教师信号是知识蒸馏成功的关键。解决 OPD 中教师信号随位置衰减的问题，对于提升蒸馏效率、稳定性和最终学生性能至关重要。

## 2. 方法论

- **核心思想**：论文提出了一种极其简单的方法——早期停止 rollout（Early Stopping Rollout, ESR）。核心思想是：**在学生蒸馏过程中，只滚动生成前 N 个响应 token，并将蒸馏损失计算仅局限于此早期窗口中。**
- **关键技术细节**：
  - 在标准 OPD 中，损失函数是对整个学生生成序列 `y = (y1, ..., yT)` 中每个位置的 KL 散度求平均： `L_full = E[ Σ KL(π_s || π_t) ]`
  - ESR 只截取学生 rollout 的前 N 个 token： `L_ESR = E[ Σ_{t=1}^{|y|} KL(...) ]`，其中 `|y|` ≤ N。如果学生在达到 N 之前就生成了结束符（EOS），则 rollout 自然终止。
  - 除了 rollout 长度，其他所有设置（如生成温度、优化器、评分模型）与标准 OPD 相同。
- **算法流程（文字说明）**：
  1. 给定一个训练 prompt。
  2. 学生模型生成一个响应，但只保留其前 N 个 token（N << T，T 为完整响应长度）。
  3. 对于生成的每个 token，使用教师模型计算其条件概率 `π_t(· | prompt, student_prefix)`。
  4. 计算学生和教师在该截断序列上的反向 KL 散度损失。
  5. 用该损失更新学生模型参数。
- **参数选择**：文中默认 N=100。实验表明，对于大多数同系列场景，`N ∈ [50, 200]` 是一个稳健的选择，性能饱和。

## 6. 主要结论与发现

- **性能**：ESR 在所有设置下（模型系列、规模、任务、训练范式）均一致匹配或超越标准 OPD 的最佳性能。
- **效率与稳定**：ESR 训练效率极高（24倍加速，4倍显存节约），且训练极稳定，尤其在跨模型系列和跨代场景下，而标准 OPD 在这些场景下极易崩溃。
- **超越教师**：ESR 训练的学生在多个场景中甚至超越了教师模型的性能。
- **机理发现**：
  1. **级联对齐**：即使只在前 N 个 token 上训练，后部 token 的 KL 散度也会自然下降 30-40%。早期 token 包含问题的策略/规划信息，对后续推理起到级联引导作用。
  2. **子模式承诺**：ESR 训练的学生倾向于“承诺”于教师分布的某一非主导但可能更优的子模式（sub-mode），而标准 OPD 则倾向于在后期 token 上平均教师的多种模式，导致更差的结果。这解释了 ESR 有时能超越教师的原因。
  3. KL 散度和 token 熵不能完全解释 ESR 的成功，**位置是一个独立的、不可替代的选择维度**。

## 7. 优点

- **极简且高效**：ESR 是一种“一行代码”的修改，不需要改变优化目标、模型结构或数据加载方式，实现门槛极低。同时带来巨大的效率和稳定性提升。
- **机理清晰**：作者不仅提出了方法，还通过严谨的实验深入揭示了其背后的“离策略衰减”、“级联对齐”和“子模式承诺”等关键机制，为理解 OPD 提供了新视角。
- **实验完备**：实验设计全面，覆盖了模型、任务、训练策略等多种维度，有力支撑了结论。特别是对跨模型系列和跨代场景的测试，验证了方法在挑战性场景下的鲁棒性。
- **观点具有洞察力**：指出位置是一个独立的、承载重要信息的轴（axis），而不仅仅是 KL/熵的代理，这一观察对未来的蒸馏和语言模型训练研究具有启发意义。

## 8. 不足与局限

- **适用范围**：实验主要针对已经具备指令微调基础、拥有基础推理能力的学生模型。对于从零开始训练推理能力的场景，全文指出根据一项同期工作，ESR 可能不会优于完整 rollout 的 OPD。论文本身也未测试预训练模型作为学生。
- **规模限制**：实验集中在中小规模（<100B）模型和特定任务微调。在工业级大规模通用能力提升（万亿级 token 数据，百万级轨迹）场景下的有效性尚不明确。作者坦诚，在这些场景下完整 rollout 可能更优。
- **跨家族敏感性**：虽然 ESR 整体稳健，但在跨模型家族（如 Gemma→Qwen）场景下，对超参数 N 的选择更为敏感（N=50 稳定，但 N=100 可能不稳定）。这限制了其在不同差距的语言模型对中的通用性。
- **任务覆盖**：未在长序列任务（如长文档摘要、复杂多轮对话）或多模态任务上进行测试，这些任务中不同位置的 token 质量模式可能不同。
- **潜在偏差**：实验使用的模型主要来自 Qwen 和 Gemma 系列，可能无法完全代表所有 LLM 在 OPD 下的行为。结论的泛化性需在更多样化的模型家族上进一步验证。

## 摘要
在策略自蒸馏通过利用教师端的特权信息，将稀疏的验证器结果转化为密集的令牌级监督，从而提升LLM推理能力。现有方法通常假设特权信息是可信的，例如参考答案或成功轨迹。我们提出一个问题：特权信息是否可以来自经验驱动的技能库？其中检索到的技能紧凑且可复用，但也可能不相关或具有误导性。我们提出了技能条件化门控自蒸馏（SGSD），将基于技能的自蒸馏形式化为教师假设验证，而非无条件模仿。SGSD检索技能-错误对，构建多教师池，并让所有技能条件化的教师对相同的普通提示学生轨迹进行评分。验证器验证每位教师的极性：支持成功或抑制失败提供正向监督，而相反立场则被反转。随后，一个稳健的门控目标蒸馏出信息丰富的教师-学生分歧，同时抑制不确定或极端信号。在多个数学推理基准上的实验表明，SGSD始终优于GRPO，并在较弱的特权信息假设下与答案条件化OPSD保持竞争力。例如，在Qwen3-1.7B上，SGSD在AIME24、AIME25和HMMT25上平均比GRPO高出6.2%，比OPSD高出1.7%。我们的代码可在https://github.com/walawalagoose/SGSD获取。

## Abstract
On-policy self-distillation (SD) improves LLM reasoning by using teacher-side privileged information (PI) to turn sparse verifier outcomes into dense token-level supervision. Existing methods usually assume trusted PI, such as reference answers or successful traces. We ask whether PI can instead come from an experience-derived skill bank, where retrieved skills are compact and reusable but may also be irrelevant or misleading. We propose Skill-Conditioned Gated Self-Distillation (SGSD), which formulates skill-based SD as teacher hypothesis validation rather than unconditional imitation. SGSD retrieves skill-mistake pairs, constructs a multi-teacher pool, and lets all skill-conditioned teachers score the same plain-prompt student rollout. The verifier validates each teacher's polarity: supporting a success or suppressing a failure gives positive supervision, while the opposite stance is reversed. A robust gated objective then distills informative teacher-student disagreements while suppressing uncertain or extreme signals. Experiments on multiple mathematical reasoning benchmarks show that SGSD consistently improves over GRPO and remains competitive with answer-conditioned OPSD under a weaker PI assumption. For example, on Qwen3-1.7B, SGSD outperforms GRPO by 6.2% and OPSD by 1.7% on average on AIME24, AIME25, and HMMT25. Our code is available at https://github.com/walawalagoose/SGSD.

## 1. 核心问题与整体含义

- **研究动机**：强化学习使用验证奖励（RLVR）通过将模型自身生成轨迹与最终答案的二元信号结合来优化推理，但其奖励信号稀疏且延迟。在线自蒸馏（on-policy self-distillation, SD）通过教师端特权信息（privileged information, PI）克服这一局限，将稀疏结果转化为密集的令牌级监督。但现有方法假设 PI 总是可靠（如参考答案、成功轨迹），而在实际中，经验驱动的技能库可能包含不相关或误导性技能。
- **核心问题**：能否将经验技能作为训练时的特权信息，而不假定每个检索到的技能都是可信的？这需要解决三个挑战：PI 来源不确定、技能的价值依赖于轨迹结果、多教师信号可能冲突。
- **整体意义**：提出 Skill-Conditioned Gated Self-Distillation (SGSD)，将基于技能的自蒸馏转化为教师假设验证问题，而非无条件模仿，从而在更弱的 PI 假设下实现有竞争力的性能。

## 2. 方法论

- **核心思想**：维护一个结构化技能库（包含通用技能和常见错误模式），对于每个问题，检索技能-错误对构成多教师池；学生对纯问题生成轨迹；每个技能条件化的教师对相同轨迹进行打分；验证器结合轨迹结果（成功/失败）推断每位教师的极性（支持成功/抑制失败为正，反之为负）；最后通过一个鲁棒的门控目标从有信息量的教师-学生分歧中学习，同时抑制不确定或极端信号。
- **关键技术细节**：
  - **结构化技能库**：包含 `general_skills`（通用技能，含标题、原则、适用条件）和 `common_mistakes`（常见错误，含描述、原因、如何避免）。通过冷启动从种子问题提取轨迹，再汇总合并去重得到。
  - **技能-错误配对**：检索 top-K 技能与 top-K 错误，按排名配对，构成 K 个教师上下文 `ck(x) = gk ⊕ ek ⊕ x`。
  - **教师权重**：基于检索相似度 softmax 归一化得到 `αk(x)`。
  - **学生与教师分布**：学生 `pS(·|x)=πθ(·|x)`；教师 `pT^(k)(·|ck(x))=π_{θ̄}(·|ck(x))`（θ̄ 为学生参数的 stop-gradient 副本）。
  - **教师极性推断**：先计算教师支持分数 `ak = (1/T) Σ Δt`，其中 `Δt = log pT(yt) - log pS(yt)`。然后定义 polarity `ρk = sign(r)·sign(a_k)`（`r` 为验证结果，+1/‑1）。当 `a_k` 与结果同号时教师有用，异号时反转。
  - **鲁棒支持估计**：对 token 进行掩码（去除格式、思维标签等）、对 gap 进行裁剪（clip ±cΔ）、设置置信度阈值 εa，得到 `eak`，使得极性判断更稳定。
  - **门控蒸馏目标**：对每个 token 定义损失 `ℓgate(Δ) = log2 - log(1 + exp(-Δ²/(2τg)))`，该损失在 Δ 接近 0 时几乎为 0，中等差距时增长，极大差距时饱和。整体蒸馏目标为 `LSGSD = Σ αk·ρk·(平均 ℓgate over tokens)`。
  - **在线更新**：每间隔 F 步，收集近期轨迹，对成功轨迹提取新技能候选，对失败轨迹提取新错误候选，合并到动态技能库并保持容量限制。

- **算法流程（文字说明）**：
  1. 对每个问题 x，从技能库检索 K 个技能-错误对。
  2. 调用检索相似度计算教师权重 αk。
  3. 学生以纯问题为上下文采样轨迹 y，并获得验证结果 r。
  4. 对每个教师上下文 ck(x)，用 stop-gradient 教师计算 token 级 gap Δt 和鲁棒支持 eak。
  5. 根据 eak 和 r 推断极性 ρk。
  6. 计算每个教师的门控损失并加权平均，得到最终目标。
  7. 更新模型参数，并根据最近轨迹更新技能库。

## 3. 实验设计

- **数据集**：训练集为 **DAPO-Math-17K 的英文子集**；评估集为三个竞争级数学推理基准：**AIME24、AIME25、HMMT25**（均为 out-of-domain 测试）。
- **评估指标**：每问题采样 12 次（avg@12 accuracy），报告最佳检查点结果。
- **对比方法**：
  - GRPO（标准 RLVR 基线）
  - OPSD（代表自蒸馏基线，使用参考答案作为 PI，本文将其改为提供真实答案而非完整轨迹）
  - 多种技能注入变体：Base+Skill（推理时检索技能）、GRPO+Skill（训练时注入技能，评估不使用）、OPSD+Skill（教师和学生均暴露于技能）。
- **模型**：Qwen3-1.7B、Qwen3-4B、Qwen3-8B。
- **实验规模**：进行了主实验（3 模型 × 3 基准 × 多方法）、消融实验（鲁棒支持组件、极性、单教师、词汇蒸馏方式、教师更新策略、目标函数、加入答案 PI）、训练动态图（步数 vs 准确率）、进一步讨论（如 Top-100 vs 全词汇、不同教师策略、不同分歧目标等）。

## 6. 主要结论与发现

- SGSD 在所有三个模型尺度上均优于 GRPO，且在较小模型（1.7B, 4B）上接近甚至超过答案条件的 OPSD，证明了在更弱假设下使用技能作为 PI 的有效性（例如 Qwen3-1.7B 平均准确率从 37.4% 提升至 43.7%，比 GRPO 高 6.2%，比 OPSD 高 1.7%）。
- 简单技能注入（Base+Skill, GRPO+Skill, OPSD+Skill）效果不佳，表明技能应仅作为教师方 PI 而非暴露给学生。
- 教师极性验证和多教师池是关键：移除极性会导致后期崩溃，单教师池持续低于多教师。
- 鲁棒支持估计（掩码、裁剪、阈值）共同提升训练稳定性。
- 全词汇蒸馏优于 Top-100 近似；同步教师更新表现最好；门控损失优于其他分歧目标。
- 加入答案 PI 反而导致性能下降和崩溃，说明技能 PI 和答案 PI 信息结构不兼容。

## 7. 优点

- **方法创新**：首次将经验技能与自蒸馏结合，并形式化为教师假设验证问题，通过极性反转处理不可靠技能。
- **稳健性设计**：门控损失在中等分歧区域保留梯度，并抑制极端噪声，且理论分析了梯度性质（有界、局部逆向 KL 近似）。

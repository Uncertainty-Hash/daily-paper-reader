## 摘要
强化学习对于大语言模型的后训练正变得越来越重要。以往的大语言模型强化学习流程大多是同步且批交错的，这对于长周期智能体任务而言效率低下。近年来，异步强化学习作为一种更高效的替代方案出现，它通过让模型在轨迹到达时进行更新。然而，现有的异步强化学习系统通常强调吞吐量，而对训练稳定性和任务有效性探索不足。例如，一个关键挑战是广泛使用的GRPO框架中的分组采样并不自然地适用于异步智能体训练。本文提出了单次展开异步优化（SAO），以解决异步强化学习中的稳定性和离策略挑战。为了减少离策略效应并提高泛化能力，我们用单次展开采样取代分组采样，即每个提示仅使用一次展开。我们进一步通过实用的价值模型训练设计来改进这种单次展开策略。为了提高优化稳定性，我们引入了一种严格的双面词元级裁剪策略。SAO能够稳定训练一千步，并在智能体编码和推理基准（如SWE-Bench Verified、BeyondAIME和IMOAnswerBench）上持续优于GRPO及其变体。我们还证明，在模拟在线学习场景中，单次展开强化学习尤为有效，此时模型必须适应不断变化的环境。为此，SAO已成功部署在训练开源GLM-5.2模型（750B-A40B）的智能体强化学习流程中。

## Abstract
Reinforcement learning (RL) is becoming increasingly important for post-training large language models (LLMs). Previous RL pipelines for LLMs were mostly synchronous and batch-interleaved, which is inefficient for long-horizon agentic tasks. Recently, asynchronous RL has emerged as a more efficient alternative by updating the model as rollouts arrive. However, existing asynchronous RL systems often emphasize throughput, while leaving training stability and task effectiveness largely underexplored. For example, a key challenge is that group-wise sampling in the widely-used GRPO framework does not naturally fit asynchronous agentic training. In this paper, we present Single-rollout Asynchronous Optimization (SAO) to address the stability and off-policy challenges in asynchronous RL. To reduce off-policy effects and improve generalization, we replace group-wise sampling with single-rollout sampling, that is, using one rollout per prompt. We further improve this single-rollout strategy with practical value-model training designs. To improve optimization stability, we introduce a strict double-side token-level clipping strategy. SAO is able to train stably for one thousand steps and consistently outperform GRPO and its variants on agentic coding and reasoning benchmarks, such as SWE-Bench Verified, BeyondAIME, and IMOAnswerBench. We also demonstrate that single-rollout RL is particularly effective in a simulated online learning setting, where the model must adapt to changing evolving environments. To this end, SAO is successfully deployed in the agentic RL pipeline for training the open GLM-5.2 model (750B-A40B).

## 1. 核心问题与整体含义（研究动机和背景）
- **背景**：大型语言模型（LLM）的后训练阶段正越来越多地采用强化学习（RL）。传统RL流程多为同步批交错模式，即收集完整批次轨迹后才开始优化，这会导致在长周期智能体任务中大量GPU空闲等待慢轨迹（stragglers），效率低下。
- **问题**：异步RL通过轨迹到达即开始更新的方式提高了利用率，但引入了两大挑战：
  - **稳定性**：每个轨迹可能由多个版本的旧策略生成，导致严重的离策略（off-policy）问题，影响训练稳定性。
  - **任务有效性**：广泛使用的GRPO框架依赖分组采样（group-wise sampling），需要等待组内所有轨迹完成后才能进行训练，在异步场景下产生延迟驱动的离策略行为；且分组采样不适用于智能体任务中每个提示仅产生单一轨迹反馈的在线或复杂环境。
- **目标**：提出一种既能保持异步RL高效性，又能稳定训练并提升任务有效性的方法。

## 2. 方法论：核心思想、关键技术细节、算法流程
### 核心思想：单次展开异步优化（Single-rollout Asynchronous Optimization, SAO）
- 用 **单次展开（single rollout）** 替代GRPO的分组采样：每个提示只生成一条轨迹，轨迹完成后立即用于训练，避免等待和离策略延迟。
- 稳定训练：引入**严格双面词元级裁剪（Double-sided Token-level Clipping, DIS）** 和多种价值模型训练技巧。

### 关键技术细节
1. **双面重要性采样（DIS）**：
   - 直接使用 rollout 策略 π_rollout 作为行为代理，计算词元级概率比 rt(θ) = exp(log π_θ - log π_rollout)，避免跟踪历史策略 π_old 的开销。
   - 采用双面裁剪：若 rt(θ) 超出 [1-εℓ, 1+εh] 范围，则该词元的梯度被屏蔽（mask），防止极端策略偏离。
   - 公式：优化目标 L(θ) = E_t[ f(rt(θ), εℓ, εh) * A_t * log π_θ(a_t|s_t) ]，其中 f 为指示函数（在区间内保留，否则为0）。

2. **价值模型训练优化**：
   - **更快更新价值模型（Faster Value Update）**：每步策略更新后，价值网络执行 K 次更新（实验中 K=2），使价值估计更快适应策略变化。
   - **冻结注意力参数（Frozen-Attention）**：在价值模型训练中冻结注意力层参数，仅优化MoE投影层，抑制梯度爆炸，稳定训练。
   - **跳观察词元级GAE（Skip-Observation Token-level GAE）**：针对多轮智能体轨迹（动作-观察交替），修改贝尔曼目标，跳过环境反馈词元，直接基于动作间的价值计算优势，减少环境随机性噪声。
   - **扩展价值预训练数据**：增加价值模型预训练语料规模，解决“冷启动”问题。

### 算法流程
- 训练时，策略模型（π_θ）和价值模型（V_φ）并行运行。每次生成一条轨迹后，利用 rollout 时的 log-prob 计算重要性采样比率，经双面裁剪后更新策略；同时价值模型以更高频率（每步策略更新对应 K 次价值更新）使用 frozen-attention 进行训练，并采用 skip-observation GAE 计算优势。

## 7. 优点
- **方法高效且实用**：直接使用 rollout log-prob 替代旧策略跟踪，降低计算开销；单次展开消除组同步延迟，适合长周期智能体任务。
- **稳定性设计出色**：双面词元级裁剪有效控制离政策梯度爆炸；价值模型冻结注意力和更快更新策略缓解了高方差问题。
- **针对智能体任务专门优化**：skip-observation GAE 避免了环境噪声对优势估计的干扰。
- **验证充分**：不仅在标准基准上超越强基线，还在模拟在线学习场景中证明其适应能力，消融实验和训练动态分析支撑了方法论的有效性。

## 摘要
基于可验证奖励的强化学习（RLVR）是提升语言模型推理能力的强大方法，但在每个新强模型上重复运行成本高昂，因为目标模型在训练期间必须生成大量交互轨迹。随着模型规模扩大，后训练本身成为瓶颈。我们研究了一种弱到强的替代方案：在交互成本较低的小模型上运行强化学习，然后复用该强化学习所学的知识来改进更强的目标模型。直接蒸馏强化学习后的弱教师模型是不够的，因为教师的最终策略混合了有用的强化学习收益与小模型的局限性。我们提出了直接在线策略蒸馏（Direct-OPD），该方法转移教师的强化学习引起的策略变化。Direct-OPD 将强化学习后的教师与其自身的强化学习前参考进行比较，并将它们的对数比值作为密集隐式奖励传递给学生。简而言之，这一检查点对告诉我们强化学习使弱模型更可能或更不可能采取哪些动作，而 Direct-OPD 在更强的学生自己的在线策略状态上应用该信号。这直接复用了弱模型的强化学习监督信号，而无需在目标模型上运行稀疏奖励强化学习。实验表明，Direct-OPD 能够持续利用弱教师来改进更强的目标模型；值得注意的是，它仅用 8 块 A100 GPU 在 4 小时内就将 Qwen3-1.7B 在 AIME 2024 上的成绩从 48.3% 提升至 58.3%。它优于步骤匹配的直接强化学习，并支持多个策略变化的顺序组合。我们的结果表明，强化学习的结果可以作为隐式奖励信号跨模型规模复用，而不仅仅是作为可供模仿的最终模型。

## Abstract
Reinforcement learning with verifiable rewards (RLVR) is a powerful recipe for improving language-model reasoning, but it is expensive to repeat on every new strong model because the target model must generate many rollouts during training. As models scale, post-training itself becomes a bottleneck. We study a weak-to-strong alternative: run RL on a smaller model where rollouts are cheaper, then reuse what that RL run learned to improve a stronger target model. Directly distilling the post-RL weak teacher is not enough, because the teacher's final policy mixes useful RL gains with the limitations of the smaller model. We propose Direct On-Policy Distillation (Direct-OPD), which transfers the teacher's RL-induced policy shift instead. Direct-OPD compares the post-RL teacher with its own pre-RL reference and treats their log-ratio as a dense implicit reward for the student. In plain terms, the checkpoint pair tells us which actions RL made the weak model more or less likely to take, and Direct-OPD applies that signal on the stronger student's own on-policy states. This directly reuses the weak model's RL supervision signal without running sparse-reward RL on the target model. Empirically, Direct-OPD consistently leverages weaker teachers to improve stronger target models; notably, it boosts Qwen3-1.7B from 48.3% to 58.3% on AIME 2024 in just 4 hours on 8 A100 GPUs. It outperforms step-matched direct RL and enables the sequential composition of multiple policy shifts. Our results show that RL outcomes can be reused across model scales as implicit reward signals, not merely as final models to imitate.

## 2. 论文提出的方法论

### 核心思想
- 不直接模仿弱教师 RL 后的最终策略（因为该策略混入了弱模型自身的能力上限），而是提取弱教师 RL 前后的策略差异（policy shift），将其作为密集隐式奖励应用于强模型的在线采样状态上。
- 利用 KL 正则化 RL 中策略与参考策略的对数比等于奖励（的标度）这一数学等价关系，将弱模型的 RL 监督信号直接编码在策略空间中。

### 关键技术细节
- **教师策略变化（policy shift）**：定义  
  \[
  \Delta_T(y|x) = \log \pi_T(y|x) - \log \pi_{Tref}(y|x)
  \]  
  其中 \(\pi_{Tref}\) 是弱模型 RL 前的参考策略，\(\pi_T\) 是 RL 后的教师策略。该对数比在 KL 正则化 RL 框架下可解释为教师隐式奖励（up to scale and per-prompt constant）。
- **Direct-OPD 目标函数**：  
  \[
  J_{\text{Direct-OPD}}(\theta) = \mathbb{E}_{x\sim D}\left[\mathbb{E}_{y\sim \pi_\theta(\cdot|x)}[\Delta_T(y|x)] - \alpha D_{KL}(\pi_\theta(\cdot|x) \| \pi_S(\cdot|x))\right]
  \]  
  其中 \(\pi_S\) 是学生初始化策略，\(\alpha\) 控制 KL 惩罚。该目标等价于让学生以自身初始化为参考，使用小教师的隐式奖励进行 KL 正则化 RL。
- **Token 级分解**：序列级变化可分解为每步 token 级奖励 \(r_t(v) = \log \pi_T(v|s_t) - \log \pi_{Tref}(v|s_t)\)。
- **Top-k 动作空间限制与 Rao-Blackwellized 梯度**：在每个学生采样的前缀上，只考虑学生 top-k 候选 token，计算加权奖励并利用分析梯度（避免单样本高方差）。
- **自适应 KL 控制**：由于教师奖励尺度未知，设计一个基于批量平均奖励符号的自适应 \(\alpha\) 调节器，使密集奖励保持在平衡区间。

### 算法流程（文字说明）
1. 在弱模型（如 1.5B）上运行标准 RLVR（如 GRPO），获得 RL 后检查点 \(\pi_T\)，保留其初始检查点 \(\pi_{Tref}\)。
2. 将学生模型 \(\pi_\theta\) 初始化为强模型（如 7B）的预训练或微调检查点 \(\pi_S\)。
3. 对每个训练 prompt，学生在线采样响应 \(\hat{y} \sim \pi_\theta\)。
4. 在每个访问的 prefix，取学生 top-k 候选 token，计算教师变化 \(r_t(v) = \log \pi_T(v|s_t) - \log \pi_{Tref}(v|s_t)\)。
5. 计算加权奖励 \(\bar{p}_t(v) \cdot r_t(v)\) 并停止梯度，构造策略梯度损失。
6. 加上 KL 散度惩罚项（使用自适应 \(\alpha\)）。
7. 更新学生参数；重复步骤 3-6 若干步（约 300 步）。

## 3. 实验设计

### 使用的数据集/场景
- **训练数据**：Skywork-OR1-RL-Data 的数学子集，采用 DAPO 风格数学 prompt 模板。

### 对比方法
- **基线 1：On-Policy Distillation (OPD)** – 直接让学生模仿 RL 后教师最终策略。
- **基线 2：直接 RL（Direct RL）** – 在目标模型上直接运行 GRPO 式 RL（同算法、步骤数匹配）。
- **比较设置**：教师对包括 (R1-Distill-1.5B → JustRL-1.5B) 和 (Nemotron-1.5B → QuestA-Nemotron-1.5B)；学生包括 R1-Distill-7B、Qwen3-1.7B、Qwen3-4B。

### 具体实验
- **RQ1（弱到强泛化）**：在三个学生上测试单一教师对的迁移效果，包括学生初始准确率已超过教师的情况。
- **RQ2（与直接 RL 对比）**：在相同 RL 步骤数下，比较先在 1.5B 上 RL 再迁移到 7B 与直接在 7B 上 RL 的性能和计算时间。

## 6. 论文的主要结论与发现

1. Direct-OPD 能够持续将弱教师 RL 中的改进信号迁移到更强学生上，即使学生初始准确率已超过教师。
2. 与直接在大模型上运行 RL 相比，先在 1.5B 模型上 RL 再迁移到 7B，在相同 RL 步骤数下获得更好性能，且大幅降低计算成本（约一半时间）。
3. 两个不同来源的教师策略变化可以顺序叠加，进一步提升学生能力。
4. Direct-OPD 不依赖教师-学生 top-k token 重叠的增加即可实现有效迁移（与标准 OPD 不同），其训练信号是策略方向而非绝对分布。
5. 短期（2k token）的在线蒸馏训练能够泛化到更长的推理行为，且比更长响应训练更稳定。
6. 自适应 KL 控制有助于保持密集奖励在可靠区间，避免学生过度利用不可靠的局部信号。

## 7. 优点

- **方法创新**：提出用策略变化（对数比）作为隐式奖励进行在线蒸馏，数学上合理（基于 KL 正则化 RL 的最优形式），工程上高效（无需额外奖励模型或稀疏奖励 RL）。
- **计算高效**：小模型 RL + 短期在线蒸馏，显著降低后训练成本（8 GPU×4h 达到 7B 直接 RL 约 320 GPU×h 的效果）。
- **跨模型族适用**：对同族（R1 系列）和异族（Qwen3）学生均有效，教师对来自不同训练管线（JustRL、QuestA）也有效。
- **弱到强泛化能力强**：学生初始已超越教师时仍能提升，这是模仿式蒸馏无法做到的。
- **分析深入**：通过覆盖重叠、熵、响应长度、KL 自适应等多角度分析为何方法有效，提供了可信的解释。
- **顺序组合**：展示了不同 RL 训练学到的能力可以累加，具有实际意义。

## 8. 不足与局限

- **领域限制**：实验仅集中在数学推理（AIME），未涉及代码、科学推理、通用对话等场景，方法在其他领域的效果未知。
- **依赖弱教师 RL 质量**：迁移的信号质量依赖于弱模型 RL 是否学到真正有用的策略方向。如果弱教师 RL 学到的是次优或虚假的模式，迁移结果可能负面。
- **超参数敏感性**：最佳响应长度和 KL 强度仍因教师-学生对而异，尽管提出自适应 KL，但未完全自动化；实际应用可能需要每对调节。
- **未与更多弱到强方法对比**：仅与直接 RL 和 OPD 对比，未与弱到强偏好优化（WSPO）、代理调优（Proxy Tuning）等其他弱到强方法比较。
- **可扩展性待验证**：只测试了 1.5B→7B/4B 级别，未在更大跨度（如 1B→70B+）上验证，且小模型 RL 本身仍需计算资源（32 GPU×160h）。
- **稀疏奖励 RL 未涉及**：方法虽避免在目标上运行稀疏奖励 RL，但仍需弱模型进行 RL 训练，该阶段本身不便宜。若弱模型能力不足，其 RL 可能无法有效发现可迁移方向。
- **实验数量虽系统但仍有局限**：每组实验通常只展示一个种子或一次运行，未提供多次重复的方差估计。
- **实际部署考量**：需要保存和部署两个弱模型检查点（pre/post RL），增加了存储和推理时的计算开销（尽管模型较小）。

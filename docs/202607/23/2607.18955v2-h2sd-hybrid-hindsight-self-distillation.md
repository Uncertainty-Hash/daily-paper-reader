## 摘要
基于可验证奖励的强化学习（RLVR）为语言模型推理提供了可靠的结果监督，但标量轨迹奖励提供的令牌级指导有限。现有的自我蒸馏方法引入了特权教师，但通常为其分配固定角色：直接分布匹配可能破坏成功行为，而仅幅度调制在失败后提供的纠正指导很少。我们观察到成功和失败的轨迹需要不同形式的后见监督。成功的响应已经包含有效的学生生成推理路径，因此可以作为特权上下文，而不是被外部理由所替代。然而，失败的响应需要纠正性参考信息。我们提出了混合后见自我蒸馏（$\mathrm{H}^{2}\mathrm{SD}$），该方法联合调整教师上下文和更新策略以适应轨迹的正确性。对于成功的轨迹，我们从经过验证的响应和改述指令构建教师上下文，并仅使用教师重新评估原始响应令牌。这强调基本推理而非冗余内容，并在不改变奖励方向的情况下细化基于幅度的信用分配。对于失败的轨迹，通过反向KL蒸馏，由验证器确认的参考提示提供纠正性指导。受控消融实验表明，性能提升取决于结果条件路由和改述指令。在具有挑战性的推理基准上的实验表明，H$^2$SD在代表性的RLVR和自我蒸馏基线中实现了最强的整体性能，具有稳定的优化和有利的准确率-效率权衡。

## Abstract
Reinforcement learning with verifiable rewards (RLVR) provides reliable outcome supervision for language model reasoning, but a scalar trajectory reward offers limited token-level guidance. Existing self-distillation methods add a privileged teacher but typically assign it a fixed role: direct distribution matching may destabilize successful behavior, while magnitude-only modulation offers little corrective guidance after failure. We observe that successful and failed trajectories require different forms of hindsight supervision. A successful response already contains a valid student-generated reasoning path and can therefore serve as privileged context rather than being replaced by an external rationale. A failed response, however, requires corrective reference information. We introduce Hybrid Hindsight Self-Distillation ($\mathrm{H}^{2}\mathrm{SD}$), which jointly adapts teacher context and update strategy to trajectory correctness. For successful trajectories, we construct the teacher context from the verified response and a rephrasing instruction, and use the teacher only to re-evaluate the original response tokens. This emphasizes essential deductions over redundant content and refines magnitude-based credit assignment without changing the reward direction. For failed trajectories, a verifier-confirmed reference hint provides corrective guidance through reverse-KL distillation. Controlled ablations show that the gains depend on outcome-conditioned routing and the rephrasing instruction. Experiments on challenging reasoning benchmarks show that H$^2$SD achieves the strongest overall performance among representative RLVR and self-distillation baselines, with stable optimization and a favorable accuracy-efficiency trade-off.

## 2. 方法论：核心思想、关键技术细节、公式或算法流程
- **核心思想**：根据轨迹正确性选择不同蒸馏策略。
  - **成功轨迹**（奖励为正）：保留学生自身已验证的正确响应，教师接收该响应加上“改述指令”，仅重新评估原始响应令牌的概率，通过幅度调制（类似RLSD）细化信用分配，不改变奖励方向。
  - **失败轨迹**（奖励为负）：教师接收来自外部强模型生成的参考提示（包含关键中间步骤和验证答案），通过反向KL蒸馏为学生提供纠正性方向引导。
- **关键技术细节**：
  - **提示生成**：用Kimi-K2.6为每个问题生成自然语言提示，包含推理步骤和验证器确认的最终答案。仅通过特权信息构建教师分布，不直接作为教师模型（无需共享词表）。
  - **幅度调制**：对成功轨迹，使用教师对学生令牌的 log-probability 差异计算权重 \( w_t = \exp(\text{sign}(A) \cdot \Delta_t) \)，其中 \( \Delta_t = \text{sg}(\log P_T(y_t) - \log P_S(y_t)) \)，再通过 clip 得到令牌级优势 \( \hat{A}_t \)。
  - **反向KL蒸馏**：对失败轨迹，最小化从学生到教师的逆向KL散度：\( \mathcal{L}_{\text{RKL}} = \frac{1}{T} \sum_{t=1}^T D_{\mathrm{KL}}(p^S_{t,\theta} \| \text{sg}[p^{T,h}_{t,\theta}]) \)。
  - **联合目标**：\( \mathcal{L}_{\text{H²SD}} = \mathbb{E}_{x,y} [ m \mathcal{L}_{\text{RLSD}} + \gamma (1-m) \mathcal{L}_{\text{RKL}} ] \)，\( m \) 为轨迹正确性指示。
- **算法流程**：学生采样 → 根据奖励判断正确性 → 正确轨迹走 RLSD 幅度调制（教师用改述版响应），错误轨迹走反向KL蒸馏（教师用参考提示）→ 更新学生策略。

## 6. 主要结论与发现
- H²SD 在所有基准上取得最佳整体准确率（Sudoku 6×6: 76.50%, 8×8: 57.25%; Calcudoku 平均: 44.00%; Arrow Maze 平均: 24.20%），远超其他方法。
- 结果条件路由是关键：成功轨迹用幅度调制（保留奖励方向），失败轨迹用反向KL蒸馏（提供纠正）优于任意统一策略。
- 特权上下文包含过程级信息（外部提示）优于仅答案或程序化反馈。
- 改述成功响应能显著增强幅度调制的效果（Sudoku 6×6 提升 23.75%），但在反向KL蒸馏中导致熵崩溃。
- H²SD 保持稳定的策略熵，避免探索崩溃（对比反转路由）。
- 性能提升不依赖更长生成长度；H²SD 在准确率-效率帕累托前沿上。

## 7. 优点
- **自适应路由**：创新性地根据轨迹正确性分配不同的教师角色，兼顾稳定优化和纠正能力。
- **轻量教师构建**：外部模型仅生成自然语言提示，不直接作为蒸馏教师，无需共享词表；提示仅用于特权上下文，学生推理时不可见。
- **精细信用分配**：成功轨迹保留原生推理路径，通过改述和幅度调制强化关键步骤；失败轨迹通过反向KL获得明确方向。
- **实验设计严谨**：与强基线在相同提示下比较，量化了蒸馏策略和特权信息的贡献；提供熵动态和效率分析，验证方法鲁棒性。
- **泛化能力强**：在未见过的更大的 Arrow Maze 尺寸（8×8, 10×10）上仍表现最佳。

## 8. 不足与局限
- **依赖外部提示**：需要强模型（Kimi-K2.6）生成验证器确认的参考提示，预处理成本高；若提示不可靠或无法生成，可能限制应用或减少训练数据。

- **过滤数据**：只保留提示通过验证器的问题，可能遗漏难例，影响覆盖完整性。
- **无理论分析**：未提供收敛性保证或劣化边界。
- **任务局限**：评估限于三类逻辑推理（数独、计算数独、箭头迷宫），未扩展到数学、编程或其他复杂推理任务。

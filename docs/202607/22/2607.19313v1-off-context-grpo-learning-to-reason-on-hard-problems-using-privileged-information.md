## 摘要
基于可验证奖励的强化学习（RLVR）提升了大语言模型的推理能力。然而，典型的RLVR方法在难题上失败：当模型无法生成任何正确解时，它会收到零学习信号。在训练过程中提供特权指导（例如解的前缀）可以通过引导模型走向具有非零奖励的正确解来帮助克服这一学习悬崖。我们将这些轨迹称为离上下文：它们是从包含特权指导的训练提示中生成的，而目标目标则由原始的不含该指导的提示定义。我们提出Off-Context GRPO（OC-GRPO），一种对GRPO的最小修改变体，它使用引导轨迹但应用了重要性校正的目标来将更新引导回原始的无引导目标，避免了未校正引导训练中不稳定的失配。实验上，我们的算法在标准数学推理基准上平均比普通GRPO取得了3.9%的绝对提升（13.8%的相对增益），且额外成本可忽略不计。

## Abstract
Reinforcement learning with verifiable rewards (RLVR) improves reasoning in large language models. Yet, typical RLVR approaches fail on difficult problems: when a model cannot generate any correct solutions, it receives \textit{zero} learning signal. Providing privileged guidance during training, such as solution prefixes, can help overcome this learning cliff by steering the model towards {correct solutions with non-zero reward}. {We call these rollouts \textit{off-context}: they are generated from a training prompt that contains privileged guidance, while the target objective is defined by the original prompt without that guidance.} {We introduce} Off-Context GRPO (OC-GRPO), a minimally modified variant of GRPO that uses guided rollouts but applies an importance-corrected objective to steer the update back toward the original unguided objective, avoiding the mismatch that destabilizes uncorrected guided training. Empirically, our algorithm achieves a 3.9\% absolute improvement (13.8\% relative gain) over vanilla GRPO on average across standard mathematical reasoning benchmarks with negligible additional cost.

## 1. 核心问题与整体含义  
- **研究动机**：基于可验证奖励的强化学习（RLVR）通常采用组相对策略优化（GRPO）来提升大语言模型的推理能力。然而，在**难题**上（模型采样到的所有响应均不正确），奖励全部为零，组内方差消失，导致梯度为零，模型无法学习任何信号——这一现象被称为**学习悬崖**。  
- **整体含义**：为了克服学习悬崖，需要引入**特权信息**（如解题前缀或提示）在训练时引导模型产生正确轨迹。但现有方法（如POPE、BREAD、PrefixRL）直接将这些引导轨迹当作来自原问题的轨迹进行优化，产生**离上下文问题**：训练目标与实际部署目标不一致，优化过程可能偏离真正目标，甚至在小模型上导致性能倒退。  
- **核心贡献**：提出**Off-Context GRPO (OC-GRPO)**，通过重要性采样校正离上下文失配，使得引导采样产生的更新依然对准原无引导目标，同时实现行为感知的信用分配。

## 2. 方法论  
- **核心思想**：保留引导采样（生成正确奖励的轨迹），但在更新时对每个token的PPO比率进行重要性校正，校正项为：
  $$ \rho_{i,t}^{oc}(\theta) = \frac{\pi_\theta(y_{i,t} | x, y_{i,<t})}{\pi_{\theta_{\text{old}}}(y_{i,t} | g(x), y_{i,<t})} $$  
  其中 \(x\) 为原问题，\(g(x)\) 为加入特权指导后的提示。  
- **关键技术细节**：  
  - 识别硬问题：基于参考模型在64次采样中全部失败的问题。  
  - **固定引导 (OC-GRPO-Fixed)**：预先用参考模型选择最小引导级别（解题前缀长度分5级，0.2~1.0），使至少一个采样成功；整个训练过程中保持该引导级别不变。  
  - **自适应引导 (OC-GRPO-Adaptive)**：每步训练时先用当前策略尝试无引导采样，若全部失败则逐步增加引导级别直到至少一个成功。  
  - 重要性权重仅用于梯度估计，不改变KL正则化项；裁剪操作（clip ratio=0.2）保留。  
- **理论性质**：  
  - 响应级估计器对原目标无偏（Theorem 3）。  
  - 校正因子 \(\lambda_+ = p(x)/q(x) < 1\) 抑制成功轨迹过高的信用，\(\lambda_- = (1-p(x))/(1-q(x)) > 1\) 放大失败轨迹的惩罚（Lemma 1, Theorem 2），实现行为感知的信用分配。  
  - 方差由引导长度控制（而非响应总长度），引导越短方差越小（Theorem 4）。

## 摘要
强化学习通常用于利用环境反馈来训练大型语言模型。在实际应用中，环境通常提供稀疏或延迟的反馈，这使得模型难以确定其推理中的哪些行为导致了成功或失败。因此，从这些信号中有效学习是困难的，因为模型必须确定每次失败应如何指导后续迭代中有意义的行为修正。我们提出了一种训练框架，即自我回顾强化学习，该框架在每个强化学习回合中嵌入一个明确的自我回顾步骤。当首次响应失败时，模型生成自我回顾以识别问题所在，从而为改进的第二次尝试创造条件。与推理时反思方法（如Reflexion）不同，该框架通过策略梯度优化自我回顾，并通过选择性蒸馏将改进内化到基础策略中，确保其在未来回合中持续存在。跨回合记忆机制可保存成功的自我回顾，以便在训练过程中遇到类似任务时重复使用。我们使用GRPO优化器在GSM8K基准上对两个语言模型（Qwen 3-4B和OLMo-3-7B）进行了SRRL与标准RLVR基线的对比评估。SRRL在最终奖励性能上持续优于RLVR，并通过成功将反馈转化为行为改进实现了更高的学习效率。

## Abstract
Reinforcement Learning is commonly used to train large language models using environmental feedback. In applied settings, the environment usually provides sparse or delayed feedback. This makes it difficult for the model to pinpoint which actions in its reasoning led to success or failure. So, learning effectively from these signals is hard because the model must determine how each failure should inform meaningful behavioral corrections in subsequent iterations. We introduce a training framework, Self-Review Reinforcement Learning, that embeds an explicit self-review step into each RL episode. When a first-pass response fails, the model generates a self-review to identify what went wrong, which conditions an improved second attempt. Unlike inference-time reflection approaches, such as Reflexion, the framework optimizes self-review with policy gradients and internalizes improvements into the base policy via selective distillation, ensuring they persist across future episodes. A cross-episode memory keeps successful self-reviews for reuse when encountering similar tasks in future episodes during training. We evaluate SRRL against a standard RLVR baseline using the GRPO optimizer across two language models, Qwen 3-4B and OLMo-3- 7B, on GSM8K benchmark. SRRL consistently outperforms the RLVR in final reward performance and achieves greater learning efficiency by successfully transforming feedback into behavioral improvement.

- **核心问题**：在强化学习（RL）训练大型语言模型（LLM）时，环境反馈通常是稀疏、延迟的二进制奖励（成功/失败），而无法提供中间步骤的归因信息。这导致模型难以定位推理过程中的错误行为，只能通过大规模试错来间接推断修正策略，造成采样效率低下、学习不稳定。
- **背景**：传统监督微调（SFT）依赖静态数据，缺乏自我修正能力；标准RLVR（带可验证奖励的强化学习）虽然引入交互反馈，但奖励信号过于简单，无法指导模型进行结构化纠错。近年来，推理时反思方法（如Reflexion、Self-Refine）允许模型在部署时自我修正，但会引入额外计算延迟，且改进无法持久保留在策略参数中。
- **论文目标**：提出一种训练框架SRRL，在RL训练过程中嵌入显式的自我回顾（self-review）步骤，将失败经验转化为结构化的错误分析与修正策略，并通过跨回合记忆与策略蒸馏将改进内化到基础策略中，从而在不增加推理时计算的前提下实现高效、持久的学习。

### 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

- **核心思想**：在每个RL训练回合中，模型首先生成第一次回答`y1`。若环境奖励`r1`低于阈值`τ`（即失败），则模型基于问题`x`、失败回答`y1`、奖励`r1`、文本反馈`f1`以及跨回合记忆`m`生成自我回顾`Δ`（结构化错误分析与修正指南）。然后，模型基于`x`和`Δ`生成第二次改进回答`y2`。若`y2`成功（`r2 > τ`），则将`Δ`存入记忆库，并通过选择性蒸馏损失训练基础策略直接由`x`生成`y2`级别的回答，从而固化改进。
- **关键技术细节**：
  - **自我回顾条件触发**：仅当第一次回答失败时（`r1 < τ`）才进行自我回顾与第二次尝试，避免奖励黑客问题和off-policy漂移。
  - **跨回合记忆**：只存储成功的自我回顾`Δ`，用于后续训练中类似问题的检索与上下文提供。
  - **RL优化**：采用GRPO（Group Relative Policy Optimization）作为底层策略梯度优化器，对第一次回答、自我回顾和第二次回答均计算策略损失`L_policy`，其中自我回顾的奖励被设定为下游第二次回答的奖励`r2`。
  - **选择性蒸馏**：对成功的第二次回答`y2`施加蒸馏损失`L_distill = -E[log π_θ(y2|x)]`，使模型学会直接从`x`复现改进行为，无需在推理时依赖自我回顾。
  - **综合目标**：`L_SRRL = L_policy + L_distill + β·L_KL`，其中KL正则化防止策略偏离参考模型过远。

  2. 每个训练步：
     - 采样问题`x`，生成第一次回答`y1`，获取`(f1, r1)`，更新`L_policy`。

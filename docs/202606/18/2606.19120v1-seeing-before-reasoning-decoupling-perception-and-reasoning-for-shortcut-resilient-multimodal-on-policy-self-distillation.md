## 摘要
在线策略自蒸馏（OPSD）在其自身的输出序列上训练模型，并使用冻结的副本提供基于参考目标的密集令牌级目标。这对于LLM推理效果良好，但直接扩展到多模态大语言模型（MLLM）可能会产生捷径：特权目标可能主要基于文本参考目标而非图像来引导令牌。我们提出ViGOS，一种用于MLLM后训练的视觉引导在线策略自蒸馏框架。学生首先撰写视觉描述，然后推理得出最终答案。对于有效输出，仅图像的感知教师监督描述，而特权推理教师监督同一学生前缀上的推理和最终答案。参考教师仅用于无效输出以恢复输出格式。在通用视觉-语言、专家推理、视觉数学、空间定位和视觉-语言-先验基准测试中，ViGOS保持了OPSD的主要优势，并在易于产生捷径的设置中改善了基于图像的行为。

## Abstract
On-policy self-distillation (OPSD) trains a model on its own rollouts and uses a frozen copy to provide dense token-level targets conditioned on a reference target. This works well for LLM reasoning, but a direct extension to multimodal large language models (MLLMs) can create a shortcut: the privileged target may guide tokens mainly based on the text reference target rather than the image. We propose ViGOS, a visually grounded OPSD framework for MLLM post-training. The student first writes a visual description and then reasons toward the final answer. For valid rollouts, an image-only perception teacher supervises the description, while a privileged reasoning teacher supervises the reasoning and final answer on the same student prefix. A reference teacher is used only for invalid rollouts to recover the output format. Across general vision-language, expert reasoning, visual math, spatial grounding, and visual-language-prior benchmarks, ViGOS keeps the main benefits of OPSD and improves image-grounded behavior in shortcut-prone settings.

*   **整体含义**：该论文旨在解决MLLM后训练中的捷径问题，提出一种名为ViGOS（视觉引导在线策略自蒸馏）的方法，通过**解耦感知与推理**两个阶段，强制模型先看图像、再推理，从而提升模型对图像内容的依赖和鲁棒性，缓解语言先验和文本捷径带来的误导。

## 2. 论文提出的方法论

*   **核心思想**：分离感知（Perception）和推理（Reasoning）的监督信号。在训练时，学生模型首先输出一个**视觉描述**（description），然后基于该描述进行推理并给出最终答案。不同类型的教师模型只监督对应段落，防止参考答案过早影响视觉证据的生成。
*   **关键技术细节**：
    *   **学生输出结构**：`<description> d </description> <think> r </think> \boxed{a}`，其中d为视觉描述，r为推理过程，a为最终答案。
    *   **三种教师角色**（均来自冻结的同一初始MLLM副本）：
        1.  **图像感知教师（q_img）**：仅接收图像I（不接收问题x或参考答案a*），负责监督描述令牌d。这确保描述段只依赖图像。
        2.  **特权推理教师（q_rea）**：接收图像I、问题x、参考答案a*，负责监督推理和答案令牌`(r, a)`，利用参考答案引导推理。
        3.  **参考教师（q_ref）**：接收完整特权信息，仅用于处理格式无效的轨迹（如缺少分隔符、非空段等），提供格式恢复信号（反向KL散度）。
    *   **训练损失**：
        *   有效轨迹：感知损失 L_perc = KL(q_img || p_θ) 应用于描述段；推理损失 L_rea = KL(q_rea || p_θ) 应用于推理+答案段。
        *   无效轨迹：参考回退损失 L_ref = KL(p_θ || q_ref) 应用于整个轨迹。
        *   总损失：`L_ViGOS = λ_perc L_perc + λ_rea L_rea + λ_ref L_ref`。
    *   **PALR诊断指标**：特权答案泄露率（Privileged Answer Leakage Rate）量化密集纠正中来自参考答案的比例，用于分析捷径严重程度。

1.  **Vanilla OPSD存在明显的答案泄漏问题**：PALR诊断显示，在推理-答案段，17.26%（3B）和26.01%（7B）的密集教师纠正来自参考答案，表明文本捷径显著。

## 8. 不足与局限

*   **描述质量依赖模型**：学生生成的视觉描述可能不完整或错误，图像感知教师可能产生泛化描述，影响后续推理。
*   **计算开销增加**：训练时需要额外教师前向传播（三个教师角色），比Vanilla OPSD更耗时。
*   **模型规模验证有限**：仅在Qwen2.5-VL的3B和7B上验证，更大模型（如72B）或不同架构（如LLaVA）上的表现未知。
*   **先验冲突场景覆盖有限**：ViLP基准仅包含特定类型的视觉语言先验，现实世界中更多样化的捷径可能未被涵盖。
*   **格式依赖性强**：要求输出严格的结构化格式，若学生无法正确解析（无效轨迹），则需依赖参考回退，可能影响长尾响应。

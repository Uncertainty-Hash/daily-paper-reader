## 摘要
语言模型推理可以通过在测试时使用脚手架来显著提升，该脚手架在不同原语上扩展推理计算——单条轨迹内的顺序推理、独立采样的并行轨迹、以及将多条推理轨迹聚合为最终响应。然而，在后训练阶段，语言模型仅针对单条轨迹内的顺序推理进行优化。我们提出了顺序-并行-聚合强化学习（SPIRAL），这是一个框架，其中语言模型被训练为使用所有三种原语，作为统一推理计算管线的一部分。具体而言，语言模型首先并行采样一组独立轨迹，每条轨迹通过顺序思维链推理生成，然后基于这些轨迹生成最终的聚合轨迹；所有组件针对最终聚合响应的奖励进行端到端优化。为了训练该系统，SPIRAL使用集合强化学习来教会模型生成一组对聚合器集体有用的轨迹，并使用标准强化学习来教会模型将这组轨迹聚合为改进的最终响应。我们在推理任务上的实验表明，SPIRAL有效地随推理计算扩展，在三种计算原语同时扩展时，性能比GRPO提升高达11倍的扩展效率和15%的更高性能。

## Abstract
Language model reasoning can be substantially improved at test time via scaffolds that scale inference compute across different primitives -- sequential reasoning within a trace, independently sampled parallel traces, and aggregation of multiple reasoning traces into a final response. During post-training, however, language models are optimized only for sequential reasoning within a single trace. We introduce Sequential-Parallel-Aggregative Reinforcement Learning (SPIRAL), a framework in which a language model is trained to use all three primitives, as part of a unified inference compute pipeline. Concretely, the language model first samples a set of independent traces in parallel, each produced through sequential chain-of-thought reasoning, and then generates a final aggregation trace conditioned on those traces; all components are optimized end-to-end against the reward of the final aggregated response. To train this system, SPIRAL uses set reinforcement learning to teach models to produce a set of traces that are collectively useful for an aggregator and standard reinforcement learning to teach models to aggregate the set into improved final responses. Our experiments on reasoning tasks show that SPIRAL effectively scales with inference compute, outperforming GRPO by up to 11$\times$ scaling efficiency and 15% higher performance when all three compute primitives are scaled.

## 1. 核心问题与整体含义（研究动机和背景）

- **问题**：当前语言模型（LM）的后训练（post-training）仅针对单条推理轨迹（sequential chain-of-thought）进行优化，而实际测试时常常需要扩展并行采样（parallel traces）和聚合（aggregation）等计算原语。这种训练与部署之间的不匹配导致模型无法有效利用额外的推理计算资源：当顺序计算扩展时，模型容易浪费预算；当并行计算扩展时，探索不足、轨迹冗余；而在聚合时，模型不擅长验证、筛选、综合多条轨迹。因此，现有方法需要手工设计复杂的脚手架（scaffolds）来编排这些原语。

- **整体含义**：本文提出**SPIRAL（Sequential-Parallel-Aggregative Reinforcement Learning）** 框架，通过强化学习端到端地训练模型同时使用**顺序推理**（单条轨迹内的思考）、**并行推理**（独立采样多条轨迹）和**聚合推理**（综合多条轨迹生成最终输出）三种原语，从而弥合训练与测试时计算扩展的鸿沟，使模型自主学会高效的搜索与合成策略。

## 2. 方法论

### 核心思想
- 在训练中，模型首先针对一个问题 **并行独立采样** \(n\) 条搜索轨迹（search traces），每条轨迹均通过顺序思维链生成；然后模型**条件于这组轨迹和原问题**生成一条聚合轨迹（aggregation trace），该轨迹是最终输出。
- 奖励只基于最终聚合轨迹的正确性。搜索轨迹和聚合轨迹通过不同的强化学习方式联合优化：
  - **搜索轨迹（并行部分）**：采用**集合强化学习（Set RL）**，以一组轨迹为单位分配奖励（最终聚合质量），鼓励模型产出集体有用的多样化轨迹。
  - **聚合轨迹（顺序部分）**：采用**标准强化学习（如 GRPO）**，在同组内计算相对优势，训练模型有效综合候选信息。

### 关键技术细节
- **梯度分解**：总梯度 = 集合RL梯度（对搜索轨迹的联合学习信号） + 标准RL梯度（对聚合轨迹的独立奖励信号）。
- **集合RL实现**：借鉴[OHR+26]的通用配方——对每个问题采样 \(N_1\) 条搜索轨迹，从中无放回抽样 \(K\) 个大小为 \(n\) 的子集；对每个子集采样 \(N_2\) 条聚合轨迹并得到平均奖励作为该子集的分数；计算集合基线得到集合优势；再计算每个搜索轨迹的边际集合优势（包含该轨迹的所有子集的平均优势），作为该搜索轨迹的优化信号。
- **聚合轨迹优化**：在同子集内，每条聚合轨迹的优势为其自身奖励减去该子集聚合轨迹的平均奖励（per-set baseline），用于降低方差。
- **数据收集**：每批 256 个问题，每个问题采样 8 条搜索轨迹，构造 4 个大小为 4 的子集，每个子集采样 4 条聚合轨迹。总 token 预算与 GRPO 对齐（每个问题 98304 tokens）。
- **提示设计**：搜索提示为常规问题 + 逐步推理要求；聚合提示添加了“审计候选轨迹并综合正确解答”的指令，强制模型关注搜索轨迹。

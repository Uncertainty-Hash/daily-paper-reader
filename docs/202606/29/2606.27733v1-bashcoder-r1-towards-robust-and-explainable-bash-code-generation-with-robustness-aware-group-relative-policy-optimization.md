## 摘要
Bash脚本是系统管理和DevOps自动化的基石，其代码质量直接影响系统稳定性和安全性。在使用大型语言模型（LLM）自动生成Bash脚本时，会出现两个相互关联的失败：不可审计的“黑箱”推理和生成代码中的关键鲁棒性漏洞。为了解决这两个问题，我们提出了BashCoder-R1，一个用于鲁棒且可解释的Bash脚本生成的新颖框架。我们的流程结合了：（1）持续预训练（CPT），使模型专门化于Bash范式；（2）在专家验证的推理与代码样本上进行长思维链监督微调（L-CoT SFT），以模拟主动风险感知思维；（3）鲁棒感知组相对策略优化（R-GRPO），一个强化学习阶段，优化语法正确性、鲁棒性（通过shellcheck）和格式正确性的加权奖励。我们在BashBench上进行评估，该基准包含952个真实世界任务（773个单行，179个多行）。BashCoder-R1在单行/多行任务上实现了SyntaxPass（100.00%/94.97%）、RobustWarnRate（4.01%/16.47%）、RobustPass（95.99%/79.33%）、FuncRate（93.01%/93.85%）和FullRate（90.04%/73.18%），在FullRate上分别比最强基线DeepSeek-V3.2（推理）高出37.82%和20.18%。关于功能性、鲁棒性和清晰度的人工评估进一步确认BashCoder-R1获得了最高质量评级。

## Abstract
Bash scripts are the cornerstone of system administration and DevOps automation, where code quality directly impacts system stability and security. In automated Bash script generation using Large Language Models (LLMs), two interconnected failures emerge: unauditable "black box" reasoning and critical robustness vulnerabilities in generated code. To address both, we propose BashCoder-R1, a novel framework for robust and explainable Bash script generation. Our pipeline combines: (1) Continual Pre-training (CPT) to specialize the model on Bash paradigms; (2) Long Chain-of-Thought Supervised Fine-Tuning (L-CoT SFT) on expert-validated reasoning-and-code samples to emulate proactive risk-aware thinking; and (3) Robustness-Aware Group Relative Policy Optimization (R-GRPO), a reinforcement learning phase optimizing a weighted reward for syntax correctness, robustness (via shellcheck), and format correctness. We evaluate on BashBench, a new benchmark of 952 real-world tasks (773 single-line, 179 multi-line). BashCoder-R1 achieves SyntaxPass (100.00%/94.97%), RobustWarnRate (4.01%/16.47%), RobustPass (95.99%/79.33%), FuncRate (93.01%/93.85%), and FullRate (90.04%/73.18%) for single-line/multi-line tasks, outperforming the strongest baseline DeepSeek-V3.2 (Reasoning) by 37.82% and 20.18% in FullRate. Human evaluation on Functionality, Robustness, and Clarity further confirms BashCoder-R1 achieves the highest quality ratings.

## 1. 核心问题与整体含义
- **研究动机**：Bash脚本是系统管理、DevOps自动化和CI/CD的核心，其代码质量直接影响系统稳定性和安全性。然而，当前大型语言模型（LLM）在生成Bash脚本时存在两个相互关联的失败：
  - **黑箱推理**：模型无法产生透明的、可审计的推理过程，开发者无法验证设计逻辑。
  - **鲁棒性漏洞**：由于缺乏对Shell环境复杂性的深层理解，生成的代码存在致命缺陷（如未引用的变量、不当的错误处理、硬编码路径等），使得代码无法投入生产环境。
- **整体目标**：提出BashCoder-R1框架，旨在同时生成**可解释**（带有显式推理链）且**鲁棒**（通过静态分析工具shellcheck验证）的Bash脚本，弥合现有方法中的关键空白。

## 2. 方法论
### 核心思想
- 采用**三阶段训练流水线**，将领域知识注入、推理能力培养与鲁棒性强化学习相结合，使模型在生成代码前先进行显式、多步的鲁棒性推理。

### 关键技术细节
- **第一阶段：持续预训练（CPT）**
  - 数据：从Linux手册页、Stack Overflow、GitHub高星项目等来源收集676,524个唯一Bash脚本（554.40M tokens），并额外加入300,000个通用文本（255.39M tokens），总计976,524个实例（809.79M tokens）。
  - 训练：只使用纯Bash代码，不包含注释，通过重叠代码窗口（最长2048 tokens）进行下一个token预测。
  - 损失函数：标准语言建模损失 $L_{CPT} = -\frac{1}{N}\sum_{i=1}^{N}\sum_{j=1}^{T_i}\log P(x_{i,j}|x_{i,<j})$。
- **第二阶段：长链思维监督微调（L-CoT SFT）**
  - 数据：构建12,334个高质量样本（7,005单行+5,329多行），每个样本包含（指令，<think>推理链，<answer>代码）。推理链和代码均经6名资深专家人工验证，确保一致性、正确性和清晰度。
  - 训练：模型学会在生成代码前先输出结构化的推理步骤（<think>...</think>），明确分析鲁棒性要求（如错误处理、权限检查、环境隔离等）。
  - 损失函数：$L_{SFT} = -\frac{1}{M}\sum_{k=1}^{M}\sum_{l=1}^{L_k}\log P(y_{k,l}|I_k, y_{k,<l})$。
- **第三阶段：鲁棒感知组相对策略优化（R-GRPO）**
  - 数据：从SFT数据集中选出的1,824个高复杂度样本（812单行+1,012多行），用于强化学习。
  - 奖励函数：加权组合三个自动标量奖励：
    - 语法检查 $R_{\text{syntax}}$：通过 `bash -n` 则为1，否则0。
    - 鲁棒性检查 $R_{\text{robustness}}$：通过 `shellcheck` 无警告则为1，否则0。权重最高（$\beta=0.5$）。
    - 格式合规 $R_{\text{format}}$：输出包含至少三步推理的 <think> 块和 <answer> 块则为1，否则0。
    - 总奖励：$R = \alpha R_{\text{syntax}} + \beta R_{\text{robustness}} + \gamma R_{\text{format}}$，其中 $\alpha=0.3, \beta=0.5, \gamma=0.2$。
  - 训练算法：借鉴GRPO，采用裁剪策略比代理损失与KL散度惩罚相结合，避免偏离参考策略过大。
  - 推理时：采用贪心解码（temperature=0）确保确定性和复现性。

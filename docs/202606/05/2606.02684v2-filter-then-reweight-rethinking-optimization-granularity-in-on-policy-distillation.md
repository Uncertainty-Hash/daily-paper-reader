## 摘要
大语言模型中的同策略蒸馏正在从全轨迹KL监督转向更具选择性的训练范式。最近的同策略蒸馏方法越来越关注选择哪些轨迹进行学习、哪些token信息量最大、以及哪些监督信号最可靠。受此趋势启发，我们重新思考同策略蒸馏的优化粒度，并提出FiRe-OPD（先过滤，再重加权），该方法在轨迹和token两个层面联合调整监督信号。具体而言，FiRe-OPD首先过滤轨迹以移除低质量的rollout样本，然后在保留的轨迹内应用软重加权以强调信息量丰富的token。与硬token选择相比，FiRe-OPD利用软加权机制有效减轻信息损失并增强优化稳定性，从而实现更细粒度的同策略蒸馏优化。我们在强到弱、单教师和多教师设置下验证了FiRe-OPD的有效性，并展示了其相对于近期token级同策略蒸馏方法的优越性（例如，在强到弱设置下AIME 2024上提升6.25，在多教师设置下Miner上提升18.81）。我们的代码可在https://github.com/YuYingLi0/FiRe-OPD获取。

## Abstract
On-Policy distillation (OPD) in large language models is shifting from full-trace KL supervision toward more selective training paradigms. Recent OPD methods increasingly focus on selecting which trajectories to learn from, which tokens are most informative, and which supervision signals are most reliable. Motivated by this trend, we rethink optimization granularity of OPD and propose \fireicon\ FiRe-OPD (Filter, then Reweight), which jointly adjusts supervision signals at both trajectory and token levels. In details, FiRe-OPD first filters trajectories to remove low-quality rollout samples, and then applies soft reweighting within the retained trajectories to emphasize informative tokens. Compared with hard token selection, FiRe-OPD leverages a soft-weighting mechanism to effectively mitigate information loss and enhance optimization stability, thereby achieving finer-grained OPD optimization. We validate the effectiveness of FiRe-OPD across strong-to-weak, single-teacher, and multi-teacher settings, and demonstrate its superiority over recent token-level OPD methods ( (e.g., +6.25 on AIME 2024 in strong-to-weak, +18.81 on Miner in multi-teacher). Our code is available at https://github.com/YuYingLi0/FiRe-OPD.

## 1. 论文的核心问题与整体含义（研究动机和背景）

同策略蒸馏（On-Policy Distillation, OPD）已成为大语言模型（LLM）后训练中迁移推理能力的重要范式。与监督微调（SFT）相比，OPD 通过对学生自身生成的轨迹进行蒸馏，避免分布不匹配；与强化学习相比，它提供了更密集的 token 级监督。然而，标准 OPD 对所有轨迹和所有 token 施加均匀的 KL 散度监督，忽略了不同样本和不同 token 在学习价值上的巨大差异——低质量轨迹可能引入噪声，而冗余 token 则浪费梯度。

现有改进方法主要分为两类：一是仅在单一粒度（轨迹级或 token 级）上操作，缺乏联合建模；二是采用硬选择（hard selection）策略直接丢弃 token，这会导致信息永久丢失，并使优化变得不连续、不稳定。论文正是针对这两个局限性，提出一种更细粒度的、联合轨迹与 token 级优化的框架，以提升 OPD 的效率与稳定性。

## 2. 论文提出的方法论：核心思想、关键技术细节

### 核心思想
FiRe-OPD（Filter, then Reweight）采用两阶段自适应调整：

1. **轨迹级硬过滤**：基于教师模型对学生生成轨迹的置信度（平均对数概率）筛选出高质量轨迹，完全丢弃低质量轨迹。
2. **token 级软重加权**：在保留的轨迹内，结合教师置信度与学生困惑度，为每个 token 赋予连续的重要性权重，强化关键学习点。

### 关键技术细节

- **轨迹过滤**  
  定义轨迹重要性分数 `s(y) = (1/T) Σ log π_T(y_t | x, y_{<t})`，在 batch 内对所有轨迹排序，丢弃得分最低的 `p%`（默认 p=20%）。理由：当教师对学生路径的对数概率很低时，说明分布差异大，教师的监督信号不可靠，应完全去除。

- **Token 重加权**  
  - **教师置信度**：`c_Tt = 1 - H(π_T) / max_H`，熵越低（分布越尖锐）表示教师越确定。
  - **学生困惑度**：`c_St = H(π_θ) / max_H`，熵越高表示学生越需要指导。
  - **组合权重**：`w_t = (1 + α·c_Tt) × (1 + β·c_St)`，默认 α=β=1.0。
  - 权重在轨迹内部归一化，保持梯度尺度不变，得到加权优势 `˜a_t`，然后代入 PPO-clip 损失函数。

- **公式流程**（文字说明）  
  1. 学生生成轨迹 y ~ π_θ(·|x)；  
  2. 计算轨迹分数 s(y)，过滤底部 p%；  
  3. 对保留轨迹的每个 token，计算权重 w_t；  
  4. 权重归一化后乘以原始优势 a_t，得到加权优势；  
  5. 使用 PPO 风格的目标函数更新学生模型。

这种设计实现了：**轨迹级硬过滤 + token 级软加权**，两种粒度采用不同策略（硬 vs 软），因为低质量轨迹应完全移除，而 token 之间的重要性是连续谱，软加权更合适。

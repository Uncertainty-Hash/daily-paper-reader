## 摘要
异步强化学习通过将响应生成与策略优化解耦，可提升语言模型训练后阶段的吞吐量，但过时响应会引发分布漂移。标准行为校正方法通过行为策略概率、重要性比例或裁剪来控制这一漂移，这要求部署系统与学习系统之间保持令牌对齐、版本一致且数值一致的行为对数概率。我们探究是否仅利用当前策略概率即可稳定异步组相对强化学习。我们识别出一种尺度失衡失效模式：在当前策略下评估过时响应时，正负损失项可能出现在不同的负对数概率尺度上，因此零和优势不再意味着平衡的损失贡献。我们提出非对称尺度策略优化（ASymPO），该方法通过每个响应的当前平均令牌负对数概率对其令牌损失进行归一化。ASymPO无需行为策略概率，恢复了响应级别的零和平衡，并保留了非零的学习信号。我们还引入了固定负缩放基线——缩放策略优化（SPO），并在异步数学推理训练后阶段评估了这两种仅依赖当前策略的目标函数。

## Abstract
Asynchronous reinforcement learning can improve language-model post-training throughput by decoupling response generation from policy optimization, but stale responses introduce distribution drift. Standard behavior-corrected methods control this drift with behavior-policy probabilities, importance ratios, or clipping, which requires token-aligned, versioned, and numerically consistent behavior log-probabilities across rollout and learner systems. We ask whether asynchronous group-relative RL can instead be stabilized using only current-policy probabilities. We identify a scale-imbalance failure mode: when stale responses are evaluated under the current policy, positive and negative loss terms can appear at different negative log-probability scales, so zero-sum advantages no longer imply balanced loss contributions. We propose Asymmetric-Scale Policy Optimization (ASymPO), which normalizes each response's token loss by its current average token negative log-probability. ASymPO requires no behavior-policy probabilities, restores response-level zero-sum balance, and preserves a nonzero learning signal. We also introduce Scaled Policy Optimization (SPO), a fixed negative-scaling baseline, and evaluate both current-policy-only objectives in asynchronous mathematical reasoning post-training.

## 1. 核心问题与整体含义（研究动机与背景）

- **问题背景**：在大型语言模型（LLM）的训练后阶段，强化学习（RL）常用于优化奖励驱动任务（如数学推理）。为了提升吞吐量，现代系统通常将响应生成（rollout）与策略优化（learner）解耦为异步模式，但陈旧响应会导致分布漂移。
- **现有方案及其代价**：标准方法使用行为策略概率（behavior-policy probabilities）进行校正（如PPO中的重要性比率和裁剪），但这对基础设施提出严格要求：需要传递令牌级行为对数概率、保持策略版本一致、处理精度漂移等，增加了部署复杂度。
- **研究目标**：探究是否可以在**不依赖行为策略概率**的情况下，仅使用当前策略概率来稳定异步组相对RL训练，从而简化系统接口。

## 2. 提出的方法论

### 2.1 核心思想
- 识别出异步训练中尺度失衡失效模式：当正优势响应和负优势响应当前负对数概率尺度不一致时，即使优势值零和，损失贡献也会失衡，导致训练不稳定。
- 提出两种仅依赖当前策略概率的目标函数：
  - **SPO（Scaled Policy Optimization）**：对负优势响应使用固定缩放系数α（实验设为0.2）削弱其损失，简单直接。
  - **ASymPO（Asymmetric-Scale Policy Optimization）**：自适应地根据每个响应的当前平均令牌负对数概率 \(S_{\theta,g}\) 进行归一化，实现响应级损失平衡。

### 2.2 关键技术细节
- **符号定义**：
  - 对于提示x，组内响应{y_g}，奖励r_g，优势A_g = r_g - 均值(r)。
  - 平均令牌负对数概率 \(S_{\theta,g} = -\frac{1}{m_g}\sum_i \log \pi_\theta(a_{g,i}|...)\)。
- **ASymPO 损失函数**：
  \[
  L_{\text{ASymPO}}(\theta) = \frac{1}{G}\sum_{g=1}^G A_g \frac{S_{\theta,g}}{\text{sg}(S_{\theta,g})}
  \]
  其中sg(·)为停止梯度算子（前向为1，反向视为常数）。
- **理论性质**（定理2）：在前向计算中，每个响应的贡献正好等于|A_g|，因此正负优势的总损失贡献严格零和平衡；梯度仍保持正确的策略梯度方向。
- **与行为校正方法的对比**：ASymPO只需传递令牌和标量奖励，无需行为对数概率、版本标签或精度重算（见表1）。

## 6. 主要结论与发现

1. **当前策略概率单独训练会不稳定**：naive loss和GPG在多模型族上均出现训练崩溃，训练奖励曲线后期骤降。
2. **SPO和ASymPO可稳定训练**：两者均无需行为概率，且能保持训练奖励平稳，产生可用最终检查点。
3. **性能与GRPO可比甚至更优**：
   - 在LLaMA-3.2-3B-Instruct上，ASymPO平均mean@8和pass@8均超越GRPO。
   - 在Qwen3-1.7B和4B上，与GRPO接近，部分基准上更好。
   - 额外实验（DAPO数据）中，ASymPO和SPO均优于GRPO。
4. **ASymPO的自适应优于SPO的固定缩放**：在部分模型上ASymPO总体表现更好，但优势不完全一致；ASymPO无需手工调参。
5. **行为概率信息并非必要**：证明通过尺度归一化即可解决异步RL中的主要不稳定性，简化了系统接口（表1）。

## 7. 优点

- **方法简洁且理论扎实**：ASymPO仅需当前策略概率，前向完美平衡正负损失（定理2），且保留梯度信号。代码实现改动小。
- **基础设施简化**：消除行为对数概率的传输、版本对齐和精度重算需求，降低分布式RL系统部署成本。
- **实验客观性**：对比方法全面（包括崩溃基线），观察到GPG也崩溃说明问题本质是尺度失衡而非简单避免重要性采样。补充实验验证不同数据源的一致性。
- **应用价值**：为大规模异步后训练提供更轻量化、更稳定的替代方案，尤其适合不希望或难以维护行为概率信息的生产环境。

## 8. 不足与局限

- **适用范围窄**：仅测试数学推理（结果可验证），未验证于学习型奖励模型、安全对齐、多步推理或智能体任务。扩展性未知。
- **未完全解决分布漂移**：ASymPO仅修正尺度失衡，不直接约束策略比值；当行为策略与当前策略差距极大时，仍可能失效。
- **SPO依赖人工α**：虽作为基线提出，但其性能依赖α选择（文中经验设为0.2，可能不泛化）。
- **实验规模有限**：模型最大为4B参数，训练数据仅4k条，无法推断在十亿/百亿参数模型和更大数据集上的行为。算力细节缺失，难以复现成本。

- **理论分析侧重平衡而非收敛**：虽证明平衡性质，但未证明ASymPO保证收敛或避免策略坍塌的充分条件。

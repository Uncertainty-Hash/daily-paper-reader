## 摘要
在策略自蒸馏中，语言模型以特权上下文为条件来监督自身生成，为稀疏奖励强化学习提供了有前景的密集监督。实际上，它可以实例化为一个辅助的全词汇学生到教师的反向KL散度损失。因此，我们提出了SDPG，一种自蒸馏策略梯度框架，该框架结合了群体相对验证器优势、归一化标准差、精确的全词汇在策略自蒸馏以及参考策略KL正则化。实验表明，SDPG在稳定性和性能上优于RLVR和自蒸馏基线。代码可在https://github.com/lauyikfung/SDPG获取。

## Abstract
On-policy self-distillation, where a language model conditions on privileged context to supervise its own generations, is a promising source of dense supervision for sparse-reward reinforcement learning. Actually, it can be instantiated as an auxiliary full-vocabulary student-to-teacher reverse Kullback-Leibler divergence loss. We therefore propose SDPG, a self-distilled policy-gradient framework that combines group-relative verifier advantages with normalized standard deviation, exact full-vocabulary on-policy self-distillation, as well as reference-policy KL regularization. Empirically, SDPG improves stability and performance over RLVR and self-distillation baselines. The code is available at https://github.com/lauyikfung/SDPG.

## 1. 核心问题与整体含义（研究动机和背景）

- **核心问题**：在基于可验证奖励的强化学习（RLVR）中，通常使用稀疏的序列级奖励（如正确/错误的二元信号），导致每个token的信用分配困难，尤其是在长序列推理任务中，模型难以定位具体出错步骤。此外，早期训练阶段的负优势信号可能导致训练不稳定。
- **研究动机**：现有方法如GRPO通过群体相对优势归一化缓解了部分问题，但稀疏性仍存。近期的在线策略蒸馏（OPD）通过教师模型提供稠密token级监督，但使用更大的外部教师模型带来内存负担，且异构教师信号可能破坏训练平滑性。
- **整体含义**：本文提出自蒸馏策略梯度（SDPG）框架，通过将在线自蒸馏实例化为全词汇学生到教师的逆向KL散度损失，并结合验证器信号和参考策略KL正则化，在保持稠密监督的同时避免外部教师和异构性，提升训练的稳定性和最终性能。

## 2. 方法论：核心思想、关键技术细节

### 核心思想
SDPG将在线自蒸馏（学生模型在特权上下文c下的分布作为教师）与RLVR的二元验证器奖励相结合，形成一个统一的KL正则化策略优化目标，包含三个互补的监督来源：
- **稀疏二元结果信号**（来自验证器）
- **稠密全词汇蒸馏信号**（来自特权上下文条件教师）
- **参考策略KL正则化**（锚定更新，防止偏离初始能力）

### 关键技术细节

1. **全词汇在线自蒸馏损失**：
   - 对于给定前缀$(x, y_{<t})$，定义学生分布$p_t(a)=\pi_\theta(a|x,y_{<t})$和特权教师分布$q_t(a)=\pi_\theta(a|c,x,y_{<t})$。
   - 使用学生到教师的逆向KL散度：$\ell_{\text{OPD}_{i,t}} = D_{\text{KL}}(p_{i,t} \parallel \text{SG}[q_{i,t}])$，其中SG为stop-gradient。
   - 关键推导（命题3.1）：在固定前缀和教师分支detached下，该损失的梯度等价于一个以centered log-ratio为优势的策略梯度形式，即$\tilde{L}_{\text{OPD},t}^{\text{PG}}(\theta) = -\mathbb{E}_{a\sim\bar{p}_t}[A_t^{\text{dist}}(a)\log p_t(a)]$，其中$A_t^{\text{dist}}(a) = \text{SG}[\bar{D}_t - \log(\bar{p}_t(a)/\bar{q}_t(a))]$，且$\mathbb{E}[A_t^{\text{dist}}]=0$。但实现中仍使用精确全词汇KL。

2. **奖励基础损失**：
   - 使用REINFORCE风格损失，但用群体相对优势$A_{\text{out}}$代替原始奖励，避免PPO重要性采样裁剪。损失函数为：$L_{\text{out}} = -\mathbb{E}[\frac{1}{\sum |y_i|}\sum_i\sum_t \text{SG}[A_{\text{out}}(y_i)] \log \pi_\theta(y_{i,t}|...)]$。

3. **参考策略KL正则化**：
   - 采用未归一化KL（UKL）来克服归一化KL的偏差问题。提供两种变体：
     - **UFKL**（前向UKL）：$L_{\text{SDPG-UFKL}} = L_{R\&D} + \alpha(\frac{\pi_{\text{ref}}}{\pi_\theta} + \log\frac{\pi_\theta}{\pi_{\text{ref}}})$
     - **URKL**（反向UKL）：$L_{\text{SDPG-URKL}} = L_{R\&D} + \alpha \frac{1}{2}\log^2\frac{\pi_\theta}{\pi_{\text{ref}}}$

4. **稳定化技巧**：
   - **正优势门控**：仅对验证器判断正确的轨迹（$A_{\text{out}}>0$）应用蒸馏损失，避免在错误轨迹上蒸馏可能误导。
   - **β调度器**：蒸馏系数$\beta(k)$采用warmup-decay调度，先线性增加后线性衰减，防止早期噪声和后期过度约束。

### 算法流程（Algorithm 1）
- 每次训练步：采样一批prompt和特权上下文；对每个prompt从当前策略采样G个响应；计算验证器奖励和群体相对优势；对每个响应和每个token位置计算学生、特权教师、参考分布；计算全词汇OPD损失；根据正优势门控和β调度组合损失；更新策略参数。

## 6. 主要结论与发现

- SDPG（尤其是UFKL变体）在AIME24、AIME25、AMC23上均显著优于GRPO和RLSD，达到最高或次高准确率。
- 正优势门控和β调度有效防止蒸馏信号压过验证器或导致熵塌缩（RLSD在1.7B和4B均出现熵崩溃）。
- 全词汇蒸馏提供了早期快速收敛，而KL正则化维持了稳定的策略更新和合理的响应长度。
- 纯自蒸馏基线OPCD在小模型上出现训练崩溃（准确率骤降、响应长度急剧缩短），验证了SDPG中结合验证器和正则化的必要性。

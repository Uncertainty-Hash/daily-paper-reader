## 摘要
当应用组相对策略优化（GRPO）进行GUI定位时，rollout是从单一截图视图中采样的；组常常在困难实例上全部失败，或在简单实例上全部成功，无法产生有用的相对优势。我们提出VISTA（视图一致自验证训练），一个基于GRPO的训练框架，从同一GUI实例的多个保持目标视图构建每个比较组。每个视图通过裁剪生成，保持目标元素可见并精确重映射其边界框，因此模型rollout在语义等价但几何不同的输入之间进行比较。为了稳定短坐标生成而不将强化学习变成无条件模仿，VISTA进一步添加了一个自验证的跨视图锚点：一个采用优势加权损失优化的oracle答案，从组基线中排除，仅在模型产生最大奖励rollout时激活。在五个GUI定位基准和多个Qwen骨干网络上，VISTA一致地提高了定位精度。在ScreenSpot-Pro上，它将Qwen3-VL 4B/8B/30B-A3B从55.5/52.7/53.7提升到63.4/65.8/67.0。鲁棒性分析进一步显示了更高的最差视图准确率和更低的预测翻转率。

## Abstract
When applying Group Relative Policy Optimization (GRPO) for GUI Grounding, rollouts are sampled from a single screenshot view; groups often become either all failures on difficult instances or all successes on easy ones, yielding no useful relative advantage. We propose VISTA (View-Consistent Self-Verified Training), a GRPO-based training framework that constructs each comparison group from multiple target-preserving views of the same GUI instance.Each view is generated by a crop that keeps the target element visible and remaps its box exactly, so model rollouts are compared across semantically equivalent but geometrically different inputs. To stabilize short coordinate generation without turning reinforcement learning into unconditional imitation, VISTA further adds a self-verified cross-view anchor: an oracle answer optimized with an advantage-weighted loss, excluded from the group baseline and activated only when the model has produced a maximum-reward rollout. Across five GUI-grounding benchmarks and multiple Qwen backbones, VISTA consistently improves grounding accuracy.On ScreenSpot-Pro, it raises Qwen3-VL 4B/8B/30B-A3B from 55.5/52.7/53.7 to 63.4/65.8/67.0. Robustness analyses further show higher worst-view accuracy and lower prediction flip rates.

# VISTA：面向GUI定位的视图一致自验证训练

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **研究背景**：GUI（图形用户界面）定位是让智能体根据自然语言指令在截图上点击准确坐标的任务。该任务对定位精度要求极高，因为UI元素通常小、密集且视觉相似。
- **核心问题**：当前先进方法采用组相对策略优化（GRPO）进行强化学习，但存在 **奖励退化** 问题：
    - 单视图采样使得困难样本组的rollout全部失败（奖励全0），或简单样本组全部成功（奖励全1），导致组内奖励方差为零，无法计算有效的相对优势，学习信号消失。
    - 论文统计显示，少于5%的固定视图训练样本能形成信息性组（即非全零或非全一的组）。
- **整体含义**：传统的GRPO组构建方式不适用于GUI定位，需要设计能够暴露语义等价但几何差异的输入，以产生非零奖励方差，从而恢复学习信号。

## 2. 论文提出的方法论

- **核心思想**：VISTA（View-Consistent Self-Verified Training）框架，从同一GUI实例的多个**目标保留视图**构建GRPO组，而不是从单一截图重复采样；并引入**自验证跨视图锚点**稳定训练，仅在模型已成功时激活监督信号。
- **关键技术细节**：
    - **视图一致组Rollout（View-Consistent Group Rollout）**：
        - 对每个训练样本，以概率 `pcrop` 生成K个目标保留裁剪视图（保持目标元素完全可见，边界框精确重映射）。
        - 每个视图对应相同的指令和不同的几何布局；从每个视图采样 `n = G/K` 个模型生成坐标，组成 `G` 个rollout的组。
        - 组统计量（均值、标准差）**仅基于模型生成的rollout计算**，与oracle无关。
    - **自验证跨视图锚点（Self-Verified Cross-View Anchor）**：
        - 仅在组内至少有一个模型rollout达到最大奖励（`Rmax = 1`）时，激活一个oracle锚点（目标框中心坐标）。
        - 锚点优势计算使用模型-only基线（`A⁺ = (Rmax - μₘ) / (σₘ + ϵ)`），但锚点自身不参与基线计算。
        - 若组内所有rollout均失败，则锚点变为零优势的no-op，避免无条件模仿。
    - **最终损失函数**：包括裁剪的GRPO目标、优势加权锚点损失和KL散度正则项。
- **算法流程**（文字说明）：
    1. 输入：截图、指令、目标框。
    2. 以概率 `pcrop` 生成K个目标保留裁剪视图，否则使用原始全屏视图（K=1）。
    3. 从每个视图采样 `G/K` 个模型生成坐标，组成G个rollout的组。
    4. 计算组内奖励均值、标准差及每个rollout的优势。
    5. 检查组内是否有成功rollout（奖励=1）：若有，则从失败视图中均匀选一个，构造oracle中心坐标作为锚点，计算其优势（使用模型-only基线），添加锚点损失；若无，则跳过锚点。
    6. 更新GRPO损失+锚点损失+KL损失。

## 7. 优点

- **泛化能力**：在多个骨干网络（Qwen3-VL、Qwen3.5）和尺度上均有效，表明框架不依赖特定初始化。

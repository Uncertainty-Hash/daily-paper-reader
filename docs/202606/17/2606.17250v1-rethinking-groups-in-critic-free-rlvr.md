## 摘要
强化学习已成为后训练大型语言模型的核心范式。现有的无评论家强化学习方法通常为同一问题生成一组轨迹，以估计用于优势计算的价值基准。然而，这种设计存在数据效率低、组同步障碍以及与结构化轨迹缺乏灵活性的问题。在这项工作中，我们重新审视了“组”的作用，并表明其底层功能不仅是估计基准，更是防止对负样本进行错误惩罚。基于这一见解，我们提出了负标记过滤，这是一种简单而有效的策略，可实现稳定的单轨迹训练。我们将其应用于两种批量级优势方法，在推理任务上取得了与基于组的RL技术相当的性能，并在智能体任务上表现出更强的性能。

## Abstract
Reinforcement learning (RL) has become a central paradigm for post-training large language models. Existing critic-free RL methods typically generate a group of rollouts for the same question to estimate value baselines for advantage computation. However, this design suffers from data inefficiency, group synchronization barriers, and inflexibility with structured rollouts. In this work, we revisit the role of the ``group'' and show that its underlying function is not merely to estimate baselines but to prevent false penalties on negative samples. Building on this insight, we propose negative token filtering, a simple and effective strategy that enables stable single-rollout training. We apply it to two batch-level advantage methods, achieving comparable performance on reasoning tasks and stronger performance on agentic tasks relative to group-based RL techniques.

## 2. 论文提出的方法论：核心思想、技术细节

*   **核心思想**：论文通过逆向工程，揭示了“组”的底层功能远不止是估计价值基线，其更关键的作用是**防止对负样本（错误轨迹）中的“支持性令牌”（如格式、中间推理步骤、工具调用提示等）进行错误惩罚**。当同一问题的正确和错误轨迹一起优化时，它们共享的令牌上的梯度会相互抵消（正负相消），从而保护了模型的核心能力不被错误地抑制。
*   **关键洞察与证据**：
    *   **实验发现1**：单轨迹训练的不稳定性主要来自**负样本**。通过降低对负样本的惩罚强度，训练稳定性显著提升。
    *   **实验发现2**：正负轨迹之间存在大量共享的、高概率的“支持性令牌”。在正样本的保护下，这些令牌的梯度可以被抵消。
    *   **实验发现3**：通过奇异值分解（SVD）分析权重矩阵，发现负样本的梯度能量更多地集中在权重矩阵的**前几个主导方向**上，对这些方向的错误惩罚容易导致灾难性遗忘。
*   **提出的方法：负令牌过滤（Negative Token Filtering, NTF）**
    *   **核心思想**：既然负样本的报应惩罚不应作用于所有令牌，那么就应该**过滤掉**那些高概率、可能是“支持性”的令牌，将负面更新集中在**更低概率、更可能与失败直接相关的令牌**上。
    *   **技术细节**：
        1.  **选择目标**：仅对负样本（错误轨迹）应用NTF。
        2.  **过滤机制**：计算负样本中每个令牌在当前策略模型下的生成概率，保留概率**最低的 τ (tau) 比例**的令牌（例如 τ=0.1，即只保留概率最低的10%的令牌），其余令牌被**掩码（mask）**。
        3.  **损失计算**：在计算负样本的损失项时，只对未被掩码（低概率）的令牌进行惩罚，而被掩码的令牌不贡献梯度。论文中使用了修改后的损失函数（如公式8所示），分母仍为完整序列长度。
    *   **实现方式**：NTF作为一个即插即用的模块，被集成到两种已有的**批量级优势计算**方法（REINFORCE++ 和 Contrastive-REINFORCE C-RF）中，使它们能够稳定地使用**单轨迹**进行训练。

## 摘要
大型语言模型（LLMs）在单个提示中给出所有指令时通常能解决任务，但当相同信息在多次对话中逐步揭示时则失败。当干净的完整提示和原始分片对话包含相同的完整用户证据时，模型仍应得出相同的答案。我们认为造成这一差距的关键原因是自我锚定漂移：在部分信息下产生的响应引入了未经支持的假设，而这些假设后来扭曲了最终答案。为减少这种影响，我们提出了规范上下文在策略蒸馏（CCOPD）。在训练期间，相同的基础模型被用作两个角色：一个基于干净完整提示的冻结教师，以及一个通过多轮对话逐步接收相同证据的可训练学生；CCOPD将学生在其自身轨迹上的行为与教师的规范全上下文行为对齐。仅在数学问题对话上训练，CCOPD在数学和五个零样本域外任务族中，相对于原始基础模型在原始分片性能上实现了32%的平均相对提升，同时基本保持了全上下文性能。进一步分析表明，CCOPD加强了对用户证据的依赖，并降低了对早期助手轮次污染的敏感性。

## Abstract
Large language models (LLMs) often solve a task when all instructions are given in a single prompt, but fail when the same information is revealed gradually across turns. When a clean FULL prompt and a RAW-SHARDED conversation contain the same complete user evidence, the model should still arrive at the same answer. We argue that a key reason for this gap is self-anchored drift: responses produced under partial information introduce unsupported assumptions, and those assumptions later distort the final answer. To reduce this effect, we propose Canonical-Context On-Policy Distillation (CCOPD). During training, the same base model is used in two roles: a frozen teacher conditioned on the clean FULL prompt and a trainable student that receives the same evidence incrementally through a multi-turn conversation; CCOPD aligns the student's behavior on its own trajectories with the teacher's canonical full-context behavior. Trained only on math problem conversations, CCOPD yields a 32\% average relative improvement in RAW-SHARDED performance over the original base model across math and five zero-shot out-of-domain task families, while largely preserving full-context performance. Further analyses suggest that CCOPD strengthens grounding in user evidence and reduces sensitivity to contamination from earlier assistant turns.

### 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：大型语言模型在单轮完整提示（FULL）下能够正确完成任务，但当相同的用户信息在多轮对话中逐步揭示（RAW-SHARDED）时，模型经常给出错误答案。这种“相同证据、不同答案”的失败模式被称为**规范上下文不一致**。
- **背景与动机**：真实用户交互通常通过多轮对话逐步提供信息，模型必须处理自身在信息不完整时生成的早期响应。这些早期响应可能引入未经验证的假设或错误（称为**自锚定漂移**），从而污染后续的最终答案。现有解决方案多依赖推理时修复（如反思、重置）或澄清机制，但这些方法修改了推理流程或依赖外部控制。作者认为模型应内化一种核心能力：一旦最终轮提供了完整的用户证据，模型的答案必须锚定于该证据，而非被自身早期的输出带偏。

### 2. 论文提出的方法论：核心思想、关键技术细节

- **核心思想**：**规范上下文在策略蒸馏（Canonical-Context On-Policy Distillation, CCOPD）**。利用同一基础模型扮演两个角色：
  - 冻结的**教师**：接收干净的完整提示（FULL），生成目标分布。
  - 可训练的**学生**：通过多轮分片交互（RAW-SHARDED）逐步接收相同证据，并用自己的策略生成最终答案前缀。
  - **对齐目标**：仅对最终答案位置，将学生**自己产生的答案前缀**同时输入教师，计算反向KL散度，迫使学生的下一个词分布向教师的分布靠拢。
- **关键技术细节**：
  - **同前缀监督**：教师和学生共享相同的答案前缀（来自学生自己的生成），但条件上下文不同（教师用FULL，学生用RAW-SHARDED历史）。
  - **最终答案掩码**：只对最终助手回复中的token计算KL损失，避免过早对齐（因为早期回复基于不完整信息）。
  - **反向KL方向**：采用反向KL（学生分布对教师分布），而非前向KL，以直接惩罚学生分配概率给教师认为低质量的候选词。
- **公式化表达**：给定任务q，教师上下文c(q)=FULL，学生上下文h(q)=RAW-SHARDED完整历史。学生生成最终答案ŷ₁...ŷ_T。损失函数为：

### 7. 优点

- **方法创新**：将多轮不一致问题归因于自锚定漂移，并采用“自蒸馏+同前缀反向KL”直接对齐规范上下文，无需外部教师或推理时修复。
- **训练高效**：仅用数学对话训练，零样本迁移至5个异构任务，表明捕获了通用的历史锚定能力。
- **机制透明**：通过SAAR、中性替换、污染测试等诊断，深入验证了CCOPD如何缓解自锚定漂移。
- **评估严谨**：统一分片协议、多任务基准、审计评估稳健性，且报告了置信区间和显著性检验。
- **实践友好**：LoRA适配器轻量（0.53%参数），训练成本低（约132 GPU-小时），可快速部署。

### 8. 不足与局限

- **实验规模有限**：主模型仅为8B参数，LoRA适配器训练数据仅6000对，未探索更大模型（如70B+）或全量微调的scaling行为。
- **任务构建人为化**：RAW-SHARDED对话是通过将完整基准任务拆分为分片构造的，真实多轮对话可能包含意图演变、提问、无关信息等复杂交互，本设置是受控近似。
- **依赖教师正确性**：CCOPD只能将学生的输出对齐至教师的FULL输出；若教师本身在FULL下出错，学生也会继承错误。
- **未训练早期行为**：该方法仅优化最终答案状态，不涉及澄清、弃权或避免过早承诺等早期交互策略。
- **开放模型偏置**：实验仅基于Qwen3和Llama3.1系列，可能不直接推广至其他架构或闭源模型。
- **潜在伦理风险**：更稳定的多轮指令遵循可能被滥用于有害任务（如误导性内容生成、社交工程），且过度的鲁棒性可能使用户过度信任错误答案。

## 摘要
强化学习（RL）自然适用于智能体知识库问答（KBQA），其中模型必须执行可执行动作、观察知识库反馈并最终返回答案。然而，当前基于RL的KBQA系统主要优化来自最终答案的稀疏奖励，导致中间动作错误监督不足。这对于逻辑形式标注的KBQA基准尤其有限：黄金逻辑形式可以转换为可执行动作序列，但现有流程主要将其用于热启动数据构建，而非用于策略内RL更新。我们提出GAPD，一种训练时的黄金动作策略蒸馏框架，为基于结果的RL添加密集的词元级指导。为了将黄金动作与策略内学生采样对齐，GAPD使用中锚匹配：它将学生探索和黄金执行期间到达的中间实体视为状态锚点，并通过这些探索到的实体集将学生状态与黄金状态匹配。基于对齐的黄金动作的当前策略作为停止梯度教师，其词元分布被蒸馏回生成动作词元跨度上的普通学生策略。GAPD在WebQSP、GrailQA和GraphQ上一致超越当前最高水平。

## Abstract
Reinforcement learning (RL) is a natural fit for agentic knowledge base question answering (KBQA), where a model must issue executable actions, observe knowledge-base feedback, and eventually return an answer. However, current RL-based KBQA systems mainly optimize sparse rewards from the final answer, leaving intermediate action errors weakly supervised. This is especially limiting for logical-form annotated KBQA benchmarks: gold logical forms can be converted into executable action sequences, but existing pipelines use them mainly for warm-start data construction rather than for on-policy RL updates. We propose GAPD, a training-time Gold-Action Policy Distillation framework that adds dense token-level guidance to outcome-based RL. To align gold actions with on-policy student rollouts, GAPD uses MID-ANCHOR MATCHING: it treats the intermediate entities reached during student exploration and gold execution as state anchors, and matches student states to gold states through these explored entity sets. The current policy conditioned on this aligned gold action serves as a stop-gradient teacher, whose token distribution is distilled back to the ordinary student policy over generated action-token spans. GAPD consistently surpasses the current state of the art on WebQSP, GrailQA, and GraphQ.

- **研究动机**：在基于强化学习的知识库问答（KBQA）中，智能体需执行可执行动作并与知识库交互，最终返回答案。现有方法（如KBQA-R1、KnowCoder-A1）仅优化最终答案的稀疏奖励（如F1得分），导致中间动作（如关系查找、约束选择）的错误缺乏有效监督，这限制了模型在复杂推理任务中的表现。
- **背景问题**：许多KBQA基准（如WebQSP、GrailQA）提供了黄金逻辑形式（gold logical forms），可解析为可执行的动作序列。然而，现有流程仅将这些黄金动作用于热启动数据构建（如引用拒绝采样、监督式微调），而未将其集成到在线策略RL更新中，浪费了宝贵的标注信息。
- **整体含义**：本文旨在通过引入基于黄金动作的密集词元级（token-level）监督，解决强化学习KBQA中的信用分配问题，提升模型在知识图谱导航中的精确性和鲁棒性。

#### 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

- **核心思想**：GAPD（Gold-Action Policy Distillation）框架在基于结果的RL（如GRPO）基础上，利用黄金动作序列提供密集的局部指导。通过**实体锚点匹配（Entity-Anchor Matching）**将学生策略的中间状态对齐到黄金执行状态，然后将当前模型在黄金动作条件化下的教师分布（自教师，self-teacher）蒸馏回学生策略，仅在匹配的生成token上施加指导，从而避免传统行为克隆对探索的抑制。
- **关键技术细节**：
  1. **黄金动作序列解析**：从黄金逻辑形式解析出有序动作序列 \(g_1, g_2, ..., g_M\)，并执行该序列以收集中间实体集合 \(\{E(u_m)\}\)。
  2. **实体锚点匹配**：对于学生策略的每个状态 \(s_t\)，计算其到达实体集合 \(E(s_t)\) 与所有黄金状态实体集合的雅卡尔相似度 \(sim(s_t, u_m) = |E(s_t) \cap E(u_m)| / |E(s_t) \cup E(u_m)|\)，选择最佳匹配的黄金状态索引 \(m^*(t)\)。
  3. **自教师构造**：在学生上下文 \(x_t\) 中插入匹配的黄金动作 \(g_{m^*(t)+1}\) 作为教师侧提示 \(\tilde{x}_t\)；教师分布为当前策略在教师提示下的停止梯度版本 \(p_{\theta}^{teach}(\cdot|\tilde{x}_t)\)，学生分布为原始策略 \(p_{\theta}^{stud}(\cdot|x_t)\)。
  4. **令牌级优势融合**：对匹配位置的生成token，计算教师-学生对数概率差 \(d_{i,k} = \log p_{\theta}^{teach}(y_{i,k}|\tilde{x}_{i,k}) - \log p_{\theta}^{stud}(y_{i,k}|x_{i,k})\)，裁剪后作为词元级GAPD优势 \(A_{i,k}^{gapd}\)，并与群体相对GRPO优势 \(A_i^{grpo}\) 按权重 \(\lambda_{gapd}\) 融合：\(\hat{A}_{i,k} = A_i^{grpo} + \lambda_{gapd} \cdot A_{i,k}^{gapd}\)。
  5. **策略更新**：使用PPO式的裁剪代理损失（公式11）更新策略 \(\theta\)，其中融合优势只应用在匹配的学生生成token上；同时设置保守过滤器（跳过答案回合、跳过相同下一实体状态回合）以保护探索。
- **算法流程**（文字说明）：
  1. 学生策略在当前提示下生成一次多轮轨迹，执行动作并收集实体状态。
  2. 执行黄金动作序列并收集黄金实体状态。
  3. 对学生轨迹的每个回合，通过实体锚点匹配找到对齐的黄金状态；若匹配且滤波器未拒绝，则将该回合的学生生成token加入蒸馏掩码集合 \(I\)。
  4. 从最终答案奖励计算GRPO优势。
  5. 对掩码内的token，使用停止梯度的自教师打分，得到词元级GAPD优势。
  6. 融合优势后更新策略参数。

- 案例研究验证了GAPD能在错误的关系分支、比较器选择等关键位置施加正确的负向或正向指导。

#### 7. 优点：方法或实验设计上的亮点

- **方法论创新**：
  - 首次将黄金动作序列集成到在线策略RL更新中，以自蒸馏形式提供密集token级监督，而非单纯的离线模仿。
  - 实体锚点匹配巧妙利用知识图谱中的实体集合作为状态锚点，实现学生-黄金状态鲁棒对齐，避免硬性回合索引对齐。
  - 停止梯度自教师设计既保持教师分布与学生策略一致性，又避免额外模型加载和内存开销。
- **实验严谨性**：消融覆盖核心组件，并报告多次运行的标准差；交互效率分析揭示了性能提升的来源；官方代码开源，可复现。
- **实际价值**：训练后推理零额外计算，且交互相应更少，适合部署于交互式KBQA系统。

#### 8. 不足与局限

- **训练成本**：GAPD训练时间约为纯结果RL的1.5倍，对大规模模型或数据集可能成为瓶颈（论文已承认此局限）。
- **领域限制**：方法仅在三个KBQA基准上验证，未测试于其他结构化推理任务（如TABQA、数学推理）或一般智能体场景，泛化性存疑。
- **依赖黄金动作标注**：完全依靠逻辑形式标注来提取黄金动作序列，对于无标注的数据集无法直接应用，限制了适用范围。
- **匹配阈值敏感**：实体锚点匹配采用固定Jaccard阈值（τ=0.95），论文未讨论不同数据集下最佳阈值差异，可能对特殊KB结构（如稀疏实体集）不够鲁棒。
- **未探索大规模模型**：实验基于8B参数模型，更大参数规模（如70B）下GAPD的收益和训练开销尚不明确。
- **推理时无对齐机制**：教师提示仅用于训练，推理时模型独立生成，若遇到未见过状态，可能因训练分布的偏差导致错误。

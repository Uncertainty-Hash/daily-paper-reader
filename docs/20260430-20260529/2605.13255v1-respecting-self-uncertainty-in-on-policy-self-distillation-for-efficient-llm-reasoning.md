## 摘要
在策略自蒸馏训练一个推理模型在其自身生成轨迹上，同时教师（通常是同一模型但具有特权上下文条件）提供密集的token级监督。现有目标通常均匀地加权教师token级信号，尽管教师预测分布的熵变化显著。我们提出EGRSD（熵引导强化自蒸馏），通过三个信号统一token级更新：奖励引导方向、师生似然比幅度以及所提出的教师熵置信门控，该门控降低高熵token位置的权重，同时为每个token权重维持非零下界。我们进一步引入CL-EGRSD，一种因果前瞻变体，区分持续高熵片段和其后上下文迅速变为低熵的瞬态高熵位置。在思考模式下使用Qwen3-4B和Qwen3-8B的实验表明，EGRSD和CL-EGRSD在比较的可训练方法中推进了准确率-长度前沿。

## Abstract
On-policy self-distillation trains a reasoning model on its own rollouts while a teacher, often the same model conditioned on privileged context, provides dense token-level supervision. Existing objectives typically weight the teacher's token-level signal uniformly across a chain-of-thought sequence, despite substantial variation in the entropy of the teacher's predictive distribution. We propose EGRSD (Entropy-Guided Reinforced Self-Distillation), which unifies token-level updates through three signals: a reward-grounded direction, a teacher-student likelihood-ratio magnitude, and the proposed teacher-entropy confidence gate that down-weights high-entropy token positions while maintaining a nonzero lower bound on every token weight. We further introduce CL-EGRSD, a causal-lookahead variant that distinguishes sustained high-entropy spans from transient high-entropy positions whose following context rapidly becomes low entropy. Experiments with Qwen3-4B and Qwen3-8B in thinking mode show that EGRSD and CL-EGRSD advance the accuracy-length frontier among the compared trainable methods.

## 1. 核心问题与整体含义（研究动机和背景）

- **问题背景**：大语言模型（LLM）在链式思维（CoT）推理中常生成大量冗余推理 token（如重复验证、模拟自纠错、中间推导重复），导致推理延迟和成本增加。在线策略自蒸馏（On-policy Self-Distillation）是一种缓解方法：学生模型在其自身采样轨迹上训练，教师模型（通常是同一模型但基于特权上下文如参考答案）提供密集的 token 级监督。然而，现有目标函数（如 OPSD、CRISP、RLSD）对师生之间所有 token 位置的监督信号**均匀加权**，忽略了教师预测分布熵的显著变化——有些位置是低熵确定性计算（如算术、表达式简化），有些是高熵分支点（如策略选择、归纳 vs 枚举），甚至存在短暂高熵但后续迅速低熵的“支点”位置（如话语转换、方法切换）。
- **核心动机**：均匀加权会过度强调高熵位置的高方差监督（可靠性低），而完全抑制高熵位置又会破坏支点位置携带的过渡信号。因此需要一种**熵感知的置信度门控**来动态调整每个 token 的更新权重，实现更高效的推理学习。

## 2. 方法论：核心思想、关键技术细节

- **核心思想**：将 token 级更新分解为三个信号：**奖励方向**（outcome-reward direction）、**师生似然比幅度**（teacher–student likelihood-ratio magnitude）、**教师熵置信门控**（teacher-entropy confidence gate）。通过熵门控降低高熵 token 权重，同时保留一个**非零下界**（0.1）以避免完全丢弃可能携带重要信息的支点位置。
- **EGRSD（Entropy-Guided Reinforced Self-Distillation）**：
  - 对于每个 rollout 的 token (i,t)，计算教师预测熵 \( H_{i,t} = -\sum_v p_T(v|x,s^*,y_{i,<t})\log p_T(v|x,s^*,y_{i,<t}) \)。
  - 进行 batch 全局归一化：\( \hat{H}_{i,t} = H_{i,t} / \max_{(j,k)\in C_{\text{batch}}} H_{j,k} \)。
  - 置信门控：\( \omega_{i,t} = \text{clip}(1 - \gamma \hat{H}_{i,t}, 0.1, 1) \)，其中 \(\gamma\) 控制衰减强度。
  - 最终 token 级优势：\( \tilde{A}_{i,t} = A_i \cdot w_{i,t} \cdot \omega_{i,t} \)，其中 \(A_i\) 是 sequence-level 优势，\(w_{i,t}\) 是 clipped 似然比幅度。
  - 损失函数：\( L_{\text{EGRSD}} = -\frac{1}{\sum m_{i,t}}\sum m_{i,t} \tilde{A}_{i,t} \log p_\theta(y_{i,t}|x,y_{i,<t}) \)。
- **CL-EGRSD（Causal-Lookahead EGRSD）**：
  - 针对瞬时高熵但后续迅速低熵的**支点（pivot）** 位置，用因果未来窗口 \(W\) 内的最小熵替换当前熵：\( \hat{H}^{\text{CL}}_{i,t} = \frac{\min_{j\in[t,\min(t+W,T_i)]} H_{i,j}}{\max_{(j,k)\in C_{\text{batch}}} H_{j,k}} \)。
  - 再应用相同门控 \( \omega^{\text{CL}}_{i,t} = \text{clip}(1 - \gamma \hat{H}^{\text{CL}}_{i,t}, 0.1, 1) \)。这能保护短暂高熵支点（权重恢复），同时继续衰减持续高熵（fork）。
- **教师冻结**：整个训练中教师权重保持不变（通过 LoRA 适配器禁用实现），避免教师向学生漂移导致 delta 信号崩溃。

## 6. 主要结论与发现

- **准确率-长度前沿**：EGRSD 和 CL-EGRSD 在所有可训练方法中扩展了 Pareto 前沿，在 Qwen3-8B 上取得最高平均准确率（CL-EGRSD 69.32%），同时生成长度与 OPSD 相当（约12.2k token）。
- **消融发现**：中等衰减强度（\(\gamma=0.1-0.3\)）最稳定，弱或强衰减均导致性能下降；前瞻窗口 W=5 对 8B 模型最优，对 4B 提升不一致。
- **教师更新策略**：冻结教师显著优于 EMA 和硬拷贝更新，原因是更新会使似然比信号坍缩。
- **机制验证**：高熵 token 对应的师生证据差距（|log pT - log pS|）比低熵高约 139 倍，验证了熵作为不可靠信号指标的有效性；CL-EGRSD 对支点位置的权重恢复是持续叉的 2.1 倍，实现了选择性保护。
- **跨架构诊断**：在 AceReason-Nemotron-7B 上 CL-EGRSD 是唯一超过无训练基线的可训练方法（+0.82%）；在弱基座 Olmo-3-7B 上同样避免负迁移，优于 SFT。

## 7. 优点

- **方法简洁有效**：仅添加一个乘性熵门控，不改变 rollout 分布和奖励定义，易于实现和集成。
- **理论动机清晰**：将 token 级蒸馏重新定义为方向、幅度、置信度三信号问题，并提供了几何解释（线性门控对应最坏情况收缩的端点弦）。
- **机制分析充分**：通过大规模 held-out token 分析直接验证高熵区域的不确定性，并量化了 CL-EGRSD 的支点恢复选择性。
- **跨架构验证**：在 Qwen3、AceReason、Olmo 三种不同基座上验证了方法的通用性。

## 8. 不足与局限

- **领域限制**：实验仅在数学推理上进行，未迁移到代码生成、代理推理或开放域问答，跨领域泛化性未知。
